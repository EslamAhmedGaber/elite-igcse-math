  1. Required

    $g(x) = \\dfrac{3x}{x-2}$. (a) Value excluded from domain. (b) Find *g*<sup>−1</sup>(*x*).

  2. Part (a)

    The denominator must not equal zero: *x* − 2 ≠ 0.

  3. Answer

    *x* = 2 cannot be in any domain of *g*

  4. Set y g ( x

    Set *y* = *g*(*x*) and swap *x* ↔ *y*: $$x = \\frac{3y}{y-2}$$

  5. Multiply both sides by (

    Multiply both sides by (*y*−2): *x*(*y*−2) = 3*y* ⟹ *x**y* − 2*x* = 3*y*

  6. Collect y terms and factorise

    Collect *y* terms and factorise: *x**y* − 3*y* = 2*x* ⟹ *y*(*x*−3) = 2*x*

  7. Solve for y

    Solve for *y*: $$y = \\frac{2x}{x-3}$$

  8. Note

    *g*<sup>−1</sup>(*x*) is undefined at *x* = 3, which is the range restriction of *g*(*x*) (horizontal asymptote).

Final answer

$g^{-1}(x) = \\dfrac{2x}{x-3}$

22. Nov 2025 4WM2H · Q21

Hard7 marks
Show worked solution
  1. (a) Find g ( 1)

    **(a) Find *g*(−1):** *g*(−1) = 4(−1)<sup>2</sup> + 16(−1) − 9 = 4 − 16 − 9 =  − 21

  2. Answer

    \(a\)  − 21

    **(b) Find *f**g*(*x*):** *f**g*(*x*) = *f*(*g*(*x*)) = 5(4*x*<sup>2</sup>+16*x*−9) − 3  = 20*x*<sup>2</sup> + 80*x* − 45 − 3 = 20*x*<sup>2</sup> + 80*x* − 48

  3. Answer

    \(b\) 20*x*<sup>2</sup> + 80*x* − 48

    Let *y* = 4*x*<sup>2</sup> + 16*x* − 9. We must rearrange to make *x* the subject.

    **Step 1: Complete the square for the *x* terms.** *y* = 4(*x*<sup>2</sup>+4*x*) − 9 *y* = 4((*x*+2)<sup>2</sup>−4) − 9 *y* = 4(*x*+2)<sup>2</sup> − 16 − 9 *y* = 4(*x*+2)<sup>2</sup> − 25

    **Step 2: Rearrange for *x*.** *y* + 25 = 4(*x*+2)<sup>2</sup> $$\\frac{y + 25}{4} = (x + 2)^2$$ $$x + 2 = \\pm\\sqrt{\\frac{y + 25}{4}}$$

    Since *x* ≥  − 2, *x* + 2 is positive, so we take the positive root. $$x + 2 = \\frac{\\sqrt{y + 25}}{2}$$ $$x = \\frac{\\sqrt{y + 25}}{2} - 2$$

    **Step 3: Swap *y* for *x* to write the inverse function.**

Final answer

$g^{-1}(x) = \\frac{\\sqrt{x + 25}}{2} - 2$

When finding the inverse of a quadratic, always complete the square. The restricted domain (*x* ≥  − 2) tells you whether to take the positive or negative square root!
