14. Jun 2026 P1HR · Q20

Hard5 marks
Show worked solution
  1. Solution | Step 1
    \[y=kt^2,\qquad40=k(4^2)\quad\Longrightarrow\quad k=\frac52.\]

    Direct proportionality to t squared means a constant times t squared.

  2. Solution | Step 2
    \[t=c\sqrt[3]{x},\qquad12=c\sqrt[3]{8}=2c\quad\Longrightarrow\quad c=6.\]

    Find the second proportionality constant using the given pair of values.

  3. Solution | Step 3
    \[x=27\quad\Longrightarrow\quad t=6\sqrt[3]{27}=18.\]

    Use the cube-root relationship first.

  4. Solution | Step 4
    \[y=\frac52(18)^2=810.\]

    Substitute the new value of t into the square relationship.

Final answer

\(y=810\)

17. May 2021 P2H · Q16

Show worked solution
  1. Find inverse function

    \(A\) is inversely proportional to \(r^2\), so

    \[ A=\frac{k}{r^2} \]
  2. Use when

    Use \(A=5\) when \(r=0.3\):

    \[ 5=\frac{k}{0.3^2} \]

    \[ A^3=0.008 \]
