    \[ x=0.6121212\ldots \]
  2. Calculate value

4. Nov 2021 P1H · Q18

Medium3 marks
Show worked solution
  1. Let
    \[ y=0.4\dot{x} \]
  2. Simplify fraction

    So

    \[ y=0.4xxx\ldots \]
  3. Simplify fraction

    Multiply by \(10\) and \(100\):

    \[ 10y=4.xxx\ldots \]
    \[ 100y=4x.xxx\ldots \]
  4. Subtract

    Subtract:

    \[ 100y-10y=(4x.xxx\ldots)-(4.xxx\ldots) \]
    \[ 90y=x+36 \]
  5. Simplify fraction

    Therefore

    \[ y=\frac{x+36}{90} \]
Final answer

\(\frac{x+36}{90}\)
