2. Nov 2025 4WM2H · Q5

Medium3 marks
Show worked solution
  1. Identify matching sides

    **Step 1: Identify corresponding sides from the similar shapes.** Looking at the given angles/orientations:

  2. Left side A B corresponds

    Left side *A**B* corresponds to *E**F* and *I**J*.

  3. Top side B C corresponds

    Top side *B**C* corresponds to *F**G* and *J**K*.

  4. Right side C D corresponds

    Right side *C**D* corresponds to *G**H* and *K**L*.

  5. We are given C D

    We are given *C**D* = 60 (wait, diagram check: *B**C* is the top side labeled 60, *A**B* = 28. On middle shape *E**F* = 7, *G**H* = 18. On right shape *K**L* = 6, *J**K* is unknown). Let’s use the explicit lengths: $$\\begin{aligned} AB = 28 \\quad &\\text{corresponds to} \\quad EF = 7 \\\\ BC = 60 \\quad &\\text{corresponds to} \\quad FG \\\\ CD \\quad &\\text{corresponds to} \\quad GH = 18 \\quad \\text{and} \\quad KL = 6 \\end{aligned}$$

  6. Find scale factors

    **Step 2: Find scale factors.** Scale factor from *A**B**C**D* to *E**F**G**H* using the left sides: $$\\text{SF}\_1 = \\frac{EF}{AB} = \\frac{7}{28} = \\frac{1}{4}$$ So, $FG = BC \\times \\frac{1}{4} = 60 \\times \\frac{1}{4} = 15 \\text{ cm}$.

  7. Scale factor from E F

    Scale factor from *E**F**G**H* to *I**J**K**L* using the right sides (*G**H* and *K**L*): $$\\text{SF}\_2 = \\frac{KL}{GH} = \\frac{6}{18} = \\frac{1}{3}$$

  8. Calculate J K

    **Step 3: Calculate *J**K*.** Side *J**K* corresponds to *F**G*. $$JK = FG \\times \\text{SF}\_2 = 15 \\times \\frac{1}{3} = 5 \\text{ cm}$$

Final answer

5 cm

5. Jan 2020 P2HR · Q12

Medium3 marks
Show worked solution
  1. Each congruent isosceles triangle has

    Each congruent isosceles triangle has two angles of \(66^\circ\).

  2. Use trigonometry

    So the angle at the point between the two polygons is \[ 180^\circ-66^\circ-66^\circ=48^\circ \]

  3. The two regular polygons have

    The two regular polygons have equal interior angles. Around the point: \[ 48^\circ+I+I=360^\circ \]

    \[ 2I=312^\circ \]
    \[ I=156^\circ \]
  4. The exterior angle is
    \[ 180^\circ-156^\circ=24^\circ \]
    \[ n=\frac{360}{24}=15 \]
Final answer

\(n=15\).

8. Jun 2024 P2HR · Q12

Medium4 marks
Show worked solution
  1. Find the gradient

    Since \(BE\parallel CD\), triangles \(ABE\) and \(ACD\) are similar.

  2. Find the gradient

    Also \[ CD=1.5BE \] so \[ \frac{BE}{CD}=\frac{1}{1.5}=\frac23 \]

  3. Find the gradient

    Therefore \[ \frac{AE}{AD}=\frac23 \]

  4. Find the gradient

    Given \(AE=10\), \[ \frac{10}{AD}=\frac23 \]

    \[ AD=15 \]
  5. Find the gradient

    So \[ ED=AD-AE=15-10=5 \]

  6. Find the gradient

    For part (b), \[ AB=2x+5, \qquad BC=3x-5 \]

    \[ AC=AB+BC=5x \]
  7. Find the gradient

    Using similarity, \[ \frac{AB}{AC}=\frac23 \]

    \[ \frac{2x+5}{5x}=\frac23 \]
    \[ 3(2x+5)=10x \]
    \[ 6x+15=10x \]
    \[ x=3.75 \]
Final answer

(a) \(ED=5\text{ cm}\), (b) \(x=3.75\).
