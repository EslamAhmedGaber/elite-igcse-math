  1. Use index laws
    \[ 4^n=(2^2)^n=2^{2n} \]
  2. Use index laws

    So

    \[ \frac{2^k}{4^n}=\frac{2^k}{2^{2n}}=2^{k-2n} \]
  3. Use index laws

    Since this equals \(2^x\),

    \[ x=k-2n \]
Final answer

\(x=k-2n\).
