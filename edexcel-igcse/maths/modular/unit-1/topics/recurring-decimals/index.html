1. Jun 2025 P1HR · Q16

Easy2 marks
Show worked solution
  1. Let
    \[ x=0.6121212\ldots \]
  2. Calculate value

    Then \[ 10x=6.121212\ldots \]

  3. Calculate value

    and \[ 1000x=612.121212\ldots \]

  4. Subtract

    Subtract: \[ 1000x-10x=612.121212\ldots-6.121212\ldots \]

    \[ 990x=606 \]
    \[ x=\frac{606}{990}=\frac{101}{165} \]
Final answer

\(0.6121212\ldots=\dfrac{101}{165}\).

4. Nov 2021 P1H · Q18

Medium3 marks
Show worked solution
  1. Let
    \[ y=0.4\dot{x} \]
  2. Simplify fraction

    So

    \[ y=0.4xxx\ldots \]
  3. Simplify fraction

    Multiply by \(10\) and \(100\):

    \[ 10y=4.xxx\ldots \]
    \[ 100y=4x.xxx\ldots \]
  4. Subtract

    Subtract:

    \[ 100y-10y=(4x.xxx\ldots)-(4.xxx\ldots) \]
    \[ 90y=x+36 \]
  5. Simplify fraction

    Therefore

    \[ y=\frac{x+36}{90} \]
Final answer

\(\frac{x+36}{90}\)
