  1. Differentiate

    $y=2x^{5/2}-4x+3$, so $\dfrac{dy}{dx}=2\cdot\dfrac52x^{3/2}-4=5x^{3/2}-4$.

  2. Use the gradient at P

    At $P$, the gradient is $16$, so $5x^{3/2}-4=16$.

  3. Find x

    $5x^{3/2}=20$, hence $x^{3/2}=4$.

  4. Use x equals 2 to the k

Final answer

$(a)\ \dfrac{dy}{dx}=5x^{3/2}-4.\quad (b)\ k=\dfrac43$.
