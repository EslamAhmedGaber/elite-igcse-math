1. WMA11/01 January 2023 · Q4

Easy4 marks
Show worked solution
  1. Use the discriminant condition

    For no real roots, the discriminant must be negative: $b^2-4ac<0$.

  2. Substitute a, b, and c

    For $kx^2+6kx+5=0$, $a=k$, $b=6k$, and $c=5$.

  3. Form the inequality

    $(6k)^2-4(k)(5)<0$, so $36k^2-20k<0$.

  4. Solve the inequality

    $4k(9k-5)<0$, so the product is negative when $0<k<\dfrac59$.

Final answer

$0<k<\dfrac59$.

2. WMA11/01 October 2019 · Q8

Easy5 marks
Show worked solution
  1. Use a substitution

    Let $u=\sqrt{x}$. Then $x=u^2$, so the equation becomes $u^2-6u+4=0$.

  2. Solve the quadratic

    $u=\dfrac{6\pm\sqrt{36-16}}{2}=\dfrac{6\pm2\sqrt5}{2}=3\pm\sqrt5$.

  3. Return to x

    Since $u=\sqrt{x}$, $x=u^2=(3\pm\sqrt5)^2=9+5\pm6\sqrt5=14\pm6\sqrt5$.

Final answer

$x=14+6\sqrt5$ or $x=14-6\sqrt5$.

3. WMA11/01 May/June 2024 · Q4

Easy6 marks
Show worked solution
  1. Equate the curves

    $x^2+kx-9=-3x^2-5x+k$ gives $4x^2+(k+5)x-(k+9)=0$.

  2. Use one intersection only

    For a single point of intersection, the discriminant is zero.

  3. Form the condition on k

    $(k+5)^2-4(4)(-(k+9))=0$, so $k^2+26k+169=0$.

  4. Find k

    $k^2+26k+169=(k+13)^2$, so $k=-13$.

  5. Find x

    Substituting $k=-13$ gives $4x^2-8x+4=0$, so $4(x-1)^2=0$ and $x=1$.

  6. Find y

    $y=x^2+kx-9=1-13-9=-21$, so $P=(1,-21)$.

Final answer

$P=(1,-21)$.

4. WMA11/01 October 2023 · Q6

Easy6 marks
Show worked solution
  1. Clear the denominator

    $4(p-2x)=\dfrac{12+15p}{x+p}$ gives $4(p-2x)(x+p)=12+15p$.

  2. Form a quadratic in x

    Expanding gives $4p^2-4px-8x^2=12+15p$, so $8x^2+4px+12+15p-4p^2=0$.

  3. Use the discriminant condition

    For two distinct real roots, $b^2-4ac>0$.

  4. Simplify the inequality

    $(4p)^2-4(8)(12+15p-4p^2)>0$, so $144p^2-480p-384>0$.

  5. Divide and factorise

    Dividing by 48 gives $3p^2-10p-8>0$, and $3p^2-10p-8=(3p+2)(p-4)$.

  6. State the range

    The upward-opening quadratic is positive outside its roots, so $p<-\dfrac23$ or $p>4$.

Final answer

$p<-\dfrac23$ or $p>4$.

5. WMA11/01 May/June 2023 · Q2

Easy6 marks
Show worked solution
  1. Use the perimeter

    $2x+2y=350$, so $x+y=175$.

  2. Use the area

    $xy=7350$.

  3. Form a quadratic

    Using $y=175-x$, $x(175-x)=7350$, so $x^2-175x+7350=0$.

  4. Solve

    $x=\dfrac{175\pm\sqrt{175^2-4(7350)}}{2}=\dfrac{175\pm35}{2}$, giving $x=105$ or $70$.

  5. Use x > y

    Since $x>y$, $x=105$ and $y=70$.

Final answer

$x=105,\ y=70$.

6. WMA11/01 May/June 2023 · Q3

Easy6 marks
Show worked solution
  1. Complete the square

    $3x^2+12x+13=3(x^2+4x)+13$.

  2. Use (x + 2)^2

    $x^2+4x=(x+2)^2-4$, so $3(x^2+4x)+13=3(x+2)^2-12+13$.

  3. Read the features

    $y=3(x+2)^2+1$ has turning point $(-2,1)$. The y-intercept is found from $x=0$, giving $y=13$.

  4. Sketch description

    The curve is an upward-opening parabola with minimum $(-2,1)$ and y-intercept $(0,13)$.

Final answer

$(a)\ 3(x+2)^2+1.\quad (b)$ y-intercept $(0,13)$ and turning point $(-2,1)$.

7. WMA11/01 January 2022 · Q2

Easy6 marks
Show worked solution
  1. Complete the square

    $f(x)=11-4x-2x^2=-2(x^2+2x)+11$.

  2. Write in vertex form

    $-2(x^2+2x)+11=-2\big((x+1)^2-1\big)+11=13-2(x+1)^2$.

  3. Identify the graph features

    The graph is a downward-opening parabola with maximum point $(-1,13)$. The y-intercept is $f(0)=11$, so it crosses the y-axis at $(0,11)$.

  4. State the line of symmetry

    From $13-2(x+1)^2$, the line of symmetry is $x=-1$.

Final answer

$(a)\ 13-2(x+1)^2.\quad (b)\ y\text{-intercept }(0,11).\quad (c)\ x=-1$.

8. WMA11/01 January 2021 · Q2

Easy6 marks
Show worked solution
  1. Substitute the two given heights

    When $t=3$ and $H=2$, $2^3=9p+q$, so $8=9p+q$. When $t=5$ and $H=2.4$, $2.4^3=25p+q$, so $13.824=25p+q$.

  2. Solve for p and q

    Subtracting the two equations gives $16p=5.824$, so $p=0.364$. Then $8=9(0.364)+q$, giving $q=4.724$, so $q=4.72$ to 3 significant figures.

  3. Use H = 5

    For $H=5$, $125=0.364T^2+4.724$.

  4. Find T

    $T^2=\dfrac{125-4.724}{0.364}=330.428\ldots$, so $T=18.177\ldots$. Therefore $T=18.2$ years to one decimal place.

Final answer

$(a)\ p=0.364,\ q=4.72.\quad (b)\ T=18.2$ years.

9. WMA11/01 May/June 2026 · Q5

Medium7 marks
Show worked solution
  1. (a) Factor out the leading coefficient

    $-2x^2+12x+7=-2(x^2-6x)+7$.

  2. (a) Complete the square

    $x^2-6x=(x-3)^2-9$, so $-2x^2+12x+7=-2\big((x-3)^2-9\big)+7=-2(x-3)^2+25$.

  3. (b) Read the maximum from completed-square form

    Because the coefficient of $(x-3)^2$ is negative, the curve has its maximum when $(x-3)^2=0$. Hence $x=3$, and the maximum value is $y=25$, so $P=(3,25)$.

  4. (c) Find the equation of the boundary line

    The line through $O=(0,0)$ and $P=(3,25)$ has gradient $\dfrac{25}{3}$, so $l$ has equation $y=\dfrac{25}{3}x$.

  5. (c) Describe the shaded region

    Points in $R$ are below the curve, above the line, and on or to the right of the $y$-axis. Therefore $y\leq-2x^2+12x+7$, $y\geq\dfrac{25}{3}x$, and $x\geq0$.

Final answer

$(a)\ -2(x-3)^2+25.\qquad (b)\ P=(3,25).\qquad (c)\ y\leq-2x^2+12x+7,\ y\geq\dfrac{25}{3}x,\ x\geq0.$

10. WMA11/01 May/June 2025 · Q10

Medium7 marks
Show worked solution
  1. Substitute k equals 4.5

    The equation becomes $3.5x^6+4x^3+0.5=0$.

  2. Clear decimals

    Multiplying by $2$ gives $7x^6+8x^3+1=0$.

  3. Use a quadratic in x cubed

    $7x^6+8x^3+1=(x^3+1)(7x^3+1)=0$.

  4. Solve for x

    $x^3=-1$ or $x^3=-\dfrac17$, so $x=-1$ or $x=-\sqrt[3]{\dfrac17}$.

  5. View the equation as a quadratic

    Let $u=x^3$. Then the equation is $(k-1)u^2+4u+(k-4)=0$.

  6. Use no real roots

    Since every real value of $u$ gives a real $x$, the original equation has no real roots exactly when this quadratic in $u$ has no real roots.

  7. Use the discriminant

    Require $b^2-4ac<0$: $16-4(k-1)(k-4)<0$.

  8. Simplify

    $16-4(k^2-5k+4)<0$ gives $20k-4k^2<0$, so $4k(5-k)<0$.

  9. Solve the inequality

    $4k(5-k)<0$ for $k<0$ or $k>5$.

Final answer

$(a)\ x=-1,\ -\sqrt[3]{\dfrac17}.\quad (b)\ k<0\text{ or }k>5$.

11. WMA11/01 May/June 2022 · Q6

Medium7 marks
Show worked solution
  1. Rearrange the second equation

    From $y-x^3+6x=0$, we get $y=x^3-6x$.

  2. Substitute into the first equation

    $2x(x^3-6x)-3x^2=50$, so $2x^4-15x^2-50=0$.

  3. Solve the quadratic in x squared

    Let $u=x^2$. Then $2u^2-15u-50=0$, giving $u=10$ or $u=-\dfrac52$.

  4. Reject the negative value

    Since $x^2$ cannot be negative, $x^2=10$, so $x=\pm\sqrt{10}$.

  5. Find y

    $y=x^3-6x=x(x^2-6)=x(10-6)=4x$. Therefore $y=4\sqrt{10}$ when $x=\sqrt{10}$ and $y=-4\sqrt{10}$ when $x=-\sqrt{10}$.

Final answer

$(x,y)=(\sqrt{10},4\sqrt{10})$ or $(-\sqrt{10},-4\sqrt{10})$.

12. WMA11/01 January 2022 · Q3

Medium7 marks
Show worked solution
  1. Expand the first square

    $(x+\sqrt2)^2=x^2+2\sqrt2x+2$.

  2. Expand the second square

    Since $\sqrt8=2\sqrt2$, $(3x-5\sqrt8)^2=(3x-10\sqrt2)^2=9x^2-60\sqrt2x+200$.

  3. Collect terms

    $f(x)=x^2+2\sqrt2x+2+9x^2-60\sqrt2x+200=10x^2-58\sqrt2x+202$.

  4. Expand the surd equation

    $\sqrt3(4y-3\sqrt3)=5y+\sqrt3$ gives $4\sqrt3y-9=5y+\sqrt3$.

  5. Solve for y

    $y(4\sqrt3-5)=9+\sqrt3$, so $y=\dfrac{9+\sqrt3}{4\sqrt3-5}$.

  6. Rationalise the denominator

    $y=\dfrac{(9+\sqrt3)(4\sqrt3+5)}{(4\sqrt3)^2-5^2}=\dfrac{57+41\sqrt3}{23}=\dfrac{57}{23}+\dfrac{41}{23}\sqrt3$.

Final answer

$(i)\ f(x)=10x^2-58\sqrt2x+202.\quad (ii)\ y=\dfrac{57}{23}+\dfrac{41}{23}\sqrt3$.

13. WMA11/01 January 2020 · Q5

Medium7 marks
Show worked solution
  1. Factorise the cubic

    $20x^3-50x^2-30x=10x(2x^2-5x-3)=10x(2x+1)(x-3)$.

  2. Solve part (a)

    $10x(2x+1)(x-3)=0$, so $x=0$, $x=-\frac12$, or $x=3$.

  3. Use the same structure for part (b)

    Let $u=(y+3)^{1/2}$. Then the equation becomes $20u^3-50u^2-30u=0$, so $u=0$, $u=-\frac12$, or $u=3$.

  4. Reject the invalid square-root value

    Since $u=\sqrt{y+3}\ge0$, reject $u=-\frac12$. If $u=0$, then $y=-3$. If $u=3$, then $y+3=9$, so $y=6$.

Final answer

$(a)\ x=0,-\dfrac12,3.\quad (b)\ y=-3,6$.

14. WMA11/01 January 2023 · Q8

Medium8 marks
Show worked solution
  1. Find the straight line

    The line cuts the y-axis at $-12$ and the x-axis at $4$, so its gradient is $\dfrac{0-(-12)}{4-0}=3$. Hence $l$ is $y=3x-12$.

  2. Use symmetry of the quadratic

    The minimum point has x-coordinate 7. The roots are $4$ and $k$, so their midpoint is 7.

  3. Find k

    $\dfrac{4+k}{2}=7$, so $k=10$.

  4. Build the quadratic

    Let $f(x)=a(x-4)(x-10)$. Since the minimum point is $(7,-18)$, $-18=a(3)(-3)=-9a$, so $a=2$.

  5. Write f(x)

    $f(x)=2(x-4)(x-10)=2x^2-28x+80$.

  6. Identify the shaded region

    The region lies between the y-axis and $x=4$, above the line and below the curve: $0\le x\le4$ and $3x-12\le y\le2x^2-28x+80$.

Final answer

$(a)\ y=3x-12.\quad (b)\ k=10.\quad (c)\ f(x)=2(x-4)(x-10).\quad (d)\ 0\le x\le4,\ 3x-12\le y\le2x^2-28x+80$.

15. WMA11/01 May/June 2026 · Q4

Hard10 marks · main topic: Differentiation
Show worked solution
  1. (a) Rewrite the radical as a power

    $f(x)=x^3-2x^{5/2}+14$.

  2. (a) Differentiate and solve

    $f'(x)=3x^2-5x^{3/2}=x^{3/2}(3x^{1/2}-5)$. Since $x>0$, the factor $x^{3/2}$ is non-zero. Therefore $3\sqrt{x}-5=0$, so $\sqrt{x}=\dfrac53$ and $x=\dfrac{25}{9}$.

  3. (b)(i) Differentiate again

    $f''(x)=6x-\dfrac{15}{2}x^{1/2}$.

  4. (b)(i) Rearrange the given equation

    $6x-\dfrac{15}{2}x^{1/2}=66$. Multiplying by 2 and dividing by 3 gives $4x-5x^{1/2}-44=0$, as required.

  5. (b)(ii) Factorise as a quadratic in the square root

    Let $u=\sqrt{x}$, where $u\geq0$. Then $4u^2-5u-44=0$, and $(u-4)(4u+11)=0$. Hence $u=4$ or $u=-\dfrac{11}{4}$.

  6. (b)(ii) Apply the square-root restriction

    Because $u=\sqrt{x}\geq0$, the value $-\dfrac{11}{4}$ is impossible. Thus $\sqrt{x}=4$ and $x=16$, which is the only solution.

Final answer

$(a)\ x=\dfrac{25}{9}.\qquad (b)(i)\ 4x-5\sqrt{x}-44=0.\qquad (b)(ii)\ x=16\text{ is the only solution}.$

16. WMA11/01 October 2025 · Q5

Hard10 marks
Show worked solution
  1. Complete the square

    $2x^2-16x+50=2(x^2-8x)+50=2[(x-4)^2-16]+50$.

  2. Simplify the completed square

    $2x^2-16x+50=2(x-4)^2+18$.

  3. Find M

    The minimum point is $M=(4,18)$.

  4. Find the line through O and M

    Since $l$ passes through $(0,0)$ and $(4,18)$, its gradient is $\dfrac{18}{4}=\dfrac92$, so $l:y=\dfrac92x$.

  5. Find the second intersection

    Set $2x^2-16x+50=\dfrac92x$.

  6. Form the quadratic

    Multiplying by $2$ gives $4x^2-32x+100=9x$, so $4x^2-41x+100=0$.

  7. Factor and select P

    $4x^2-41x+100=(x-4)(4x-25)=0$. The point $M$ has $x=4$, so $P$ has $x=\dfrac{25}{4}$.

  8. Define the region

    The shaded region is above the line, below the curve, and between the y-axis and $M$.

  9. Write inequalities

    $\dfrac92x\le y\le2x^2-16x+50$ with $0\le x\le4$.

Final answer

$(a)\ 2(x-4)^2+18.\quad (b)\ x_P=\dfrac{25}{4}.\quad (c)\ \dfrac92x\le y\le2x^2-16x+50,\ 0\le x\le4$.

17. WMA11/01 January 2024 · Q9

Hard10 marks
Show worked solution
  1. Use symmetry for the sketch

    The maximum is at $(2,20)$ and the curve passes through $(0,0)$. Since the axis of symmetry is $x=2$, the other x-intercept is $(4,0)$.

  2. Use completed-square form

    Let $f(x)=a(x-2)^2+20$.

  3. Use the origin

    $0=a(0-2)^2+20$, so $4a=-20$ and $a=-5$.

  4. Write f(x)

    $f(x)=-5(x-2)^2+20=-5x^2+20x=-5x(x-4)$.

  5. Equate the two curves

    $-5x^2+20x=x(x^2-4)=x^3-4x$.

  6. Factorise

    $x^3+5x^2-24x=0$, so $x(x^2+5x-24)=0$ and $x(x+8)(x-3)=0$.

  7. Use the negative x-coordinate

    The negative x-coordinate is $x=-8$.

  8. Find y

    $y=x(x^2-4)=(-8)(64-4)=-480$, so $P=(-8,-480)$.

Final answer

$(a)$ downward parabola through $(0,0)$ and $(4,0)$ with maximum $(2,20)$. $(b)\ f(x)=-5x(x-4)$. $(c)\ P=(-8,-480)$.

18. WMA11/01 October 2023 · Q11

Hard10 marks
Show worked solution
  1. Complete the square

    $2x^2-12x+14=2(x^2-6x)+14=2\left((x-3)^2-9\right)+14=2(x-3)^2-4$.

  2. State the minimum point

    The minimum of $2(x-3)^2-4$ is at $P=(3,-4)$.

  3. Find the gradient of l

    The line passes through $(-1,28)$ and $P(3,-4)$, so $m=\dfrac{-4-28}{3-(-1)}=\dfrac{-32}{4}=-8$.

  4. Find the equation of l

    Using $P(3,-4)$, $y+4=-8(x-3)$, so $y=-8x+20$.

  5. Use the axes as boundaries

    The region is to the right of the y-axis and above the x-axis, so $x\ge0$ and $y\ge0$.

  6. Use the line and curve as boundaries

    The region is below the line and above the curve, so $y\le-8x+20$ and $y\ge2x^2-12x+14$.

Final answer

$(a)\ 2(x-3)^2-4.\quad (b)\ P=(3,-4).\quad (c)\ y=-8x+20.\quad (d)\ x\ge0,\ y\ge0,\ y\le-8x+20,\ y\ge2x^2-12x+14$.
