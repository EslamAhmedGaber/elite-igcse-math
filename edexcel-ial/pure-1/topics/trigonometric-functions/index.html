1. WMA11/01 January 2023 · Q9

Easy4 marks
Show worked solution
  1. State the period

    The period of $\tan x$ is $\pi$.

  2. Count roots for the steeper line

    In $-\pi<x<\pi$, the line $y=(\pi+2)x$ meets $y=\tan x$ once at the origin and once on each side of the origin, giving 3 roots.

  3. Extend to -2pi < x < 2pi

    For $y=\pi x$, the interval $-2\pi<x<2\pi$ has the 3 central roots plus one further root on each neighbouring branch, giving 5 roots.

  4. Extend to -100pi < x < 100pi

    There are 99 positive outer roots, 99 negative outer roots, and 3 central roots, so the total is $99+99+3=201$.

Final answer

$(a)\ \pi.\quad (b)(i)\ 3,\ (ii)\ 5,\ (iii)\ 201$.

3. WMA11/01 October 2019 · Q9

Easy4 marks
Show worked solution
  1. Use the scale factor inside the sine

    For $y=\sin\left(\frac{x}{12}\right)$, one full sine cycle needs $\frac{x}{12}$ to increase by $2\pi$, so the period is $24\pi$.

  2. Locate the minimum point

    The sine function is $-1$ when its angle is $\frac{3\pi}{2}$. Therefore $\frac{x}{12}=\frac{3\pi}{2}$, so $x=18\pi$ and $M=(18\pi,-1)$.

  3. Use sine symmetry

    If the smallest positive solution of $\sin\left(\frac{x}{12}\right)=k$ is $\alpha$, then the closest negative solution is one half-period before the opposite sine position: $-12\pi-\alpha$.

  4. Convert to cosine

    Since $\cos\theta=\sin\left(\frac\pi2-\theta\right)$, the corresponding smallest positive cosine solution is $6\pi-\alpha$.

Final answer

$(a)\ 24\pi.\quad (b)\ (18\pi,-1).\quad (c)(i)\ -12\pi-\alpha.\quad (ii)\ 6\pi-\alpha$.

4. WMA11/01 May/June 2026 · Q9

Easy5 marks
Show worked solution
  1. (a) Locate the minimum of C1

    A sine curve reaches its minimum when its angle is $\frac{3\pi}{2}$. Therefore $$x+\frac\pi8=\frac{3\pi}{2},$$ so $$x=\frac{12\pi}{8}-\frac\pi8=\frac{11\pi}{8}.$$

  2. (b) Write both families of roots

    For $\sin u=\sin\left(\frac\pi8\right)$, $$u=\frac\pi8+2n\pi\quad\text{or}\quad u=\frac{7\pi}{8}+2n\pi.$$ With $u=x+\frac\pi8$, this gives $$x=2n\pi\quad\text{or}\quad x=\frac{3\pi}{4}+2n\pi.$$

  3. (b) Count the roots in the interval

    For $0\le x<101\pi$, each family has $n=0,1,\ldots,50$, giving 51 roots from each family. Hence the total number of roots is $$51+51=102.$$

  4. (c) Locate the minimum of C2

    Because $y=-5\sin\left(x+\frac\pi8\right)$, the minimum value $-5$ occurs when the sine value is $1$. Thus $$x+\frac\pi8=\frac\pi2,$$ so $x=\frac{3\pi}{8}$. Therefore $$Q=\left(\frac{3\pi}{8},-5\right).$$

Final answer

$(a)\; x=\dfrac{11\pi}{8}.\qquad (b)\; 102\text{ roots}.\qquad (c)\; Q=\left(\dfrac{3\pi}{8},-5\right).$

5. WMA11/01 October 2021 · Q4

Easy5 marks
Show worked solution
  1. Find Q

    For $f(x)=\cos 2x^\circ$, the first minimum occurs when $2x=180^\circ$, so $x=90^\circ$ and $y=-1$. Therefore $Q=(90,-1)$.

  2. Find k

    The point $R(k,0)$ is the x-intercept after the next maximum. This occurs when $2x=450^\circ$, so $x=225^\circ$. Hence $k=225$.

  3. Count horizontal intersections

    A horizontal line $y=p$ gives exactly two intersections on $0\le x\le225$ when it cuts the two negative branches only, so $-1<p<0$.

  4. Include the maximum case

    There are also exactly two solutions when $p=1$, at $x=0$ and $x=180$. Therefore $-1<p<0$ or $p=1$.

Final answer

$(a)(i)\ Q=(90,-1).\quad (a)(ii)\ k=225.\quad (b)\ -1<p<0\text{ or }p=1$.

  1. Read cosine key points

    For $y=4\cos x^\circ$, the maximum value is $4$ and the minimum value is $-4$. The minimum immediately to the left of the y-axis is at $x=-180^\circ$, so $P=(-180,-4)$.

  2. Find Q from the cosine zero

    The x-intercepts of $4\cos x^\circ$ occur at $x=90^\circ,270^\circ,450^\circ,\ldots$. The point shown to the right of the next maximum is $Q=(450,0)$.

  3. Use the shifted curve C2

    For $C_2$, $y=4\cos x^\circ+k$. Its minimum is $-4+k$. Since the minimum value is $-1$, $-4+k=-1$, so $k=3$.

  4. Find R

Final answer

$(a)(i)\ P=(-180,-4).\quad (a)(ii)\ Q=(450,0).\quad (b)\ R=(360,7)$.

8. WMA11/01 May/June 2025 · Q4

Easy6 marks
Show worked solution
  1. Point P

    For $y=4\cos x$, the x-intercepts occur at $x=90^\circ+180^\circ n$. The labelled point $P$ is the right-hand intercept after $180^\circ$, so $P=(270^\circ,0)$.

  2. Point Q

    The minimum value is $-4$, reached at $x=180^\circ+360^\circ n$. The labelled point on the left is $Q=(-180^\circ,-4)$.

  3. Count part c(i)

    $4\cos x=3$ has two solutions every $360^\circ$. The interval $0<x\le18000^\circ$ contains $50$ full periods, so there are $100$ solutions.

  4. Count part c(ii)

    $5+4\cos x=1$ gives $\cos x=-1$. This occurs once every $360^\circ$. In $-720^\circ<x\le720^\circ$, the solutions are $-540^\circ,-180^\circ,180^\circ,540^\circ$, so there are $4$.

  5. Count part c(iii)

    $4\cos x-3=1$ gives $\cos x=1$. In $-1080^\circ\le x\le1080^\circ$, the multiples of $360^\circ$ are $-1080,-720,-360,0,360,720,1080$, so there are $7$.

Final answer

$(a)\ P=(270^\circ,0).\quad (b)\ Q=(-180^\circ,-4).\quad (c)(i)\ 100,\ (ii)\ 4,\ (iii)\ 7$.

  1. Use maxima of sine

    For $y=12\sin x$, maxima occur when $x=\dfrac{\pi}{2}+2\pi n$, with value $12$.

  2. Read point P

    The maximum point $P$ shown is the second positive maximum, so $P=(\dfrac{5\pi}{2},12)$.

  3. Find k for C2

    For $y=12\sin x+k$, the maximum value is $12+k$. Given the maximum is $3$, $k=-9$.

  4. Find the smallest positive minimum on C2

    The minimum value is $-12-9=-21$, and it first occurs at $x=\dfrac{3\pi}{2}$. So the point is $(\dfrac{3\pi}{2},-21)$.

  5. Find A for C3

    For $y=12\sin(x+B)$, any minimum has value $-12$, so $A=-12$.

  6. Find the smallest positive B

    At the minimum $x=\dfrac{\pi}{4}$, so $\dfrac{\pi}{4}+B=\dfrac{3\pi}{2}$. Hence $B=\dfrac{5\pi}{4}$.

Final answer

$(a)\ P=(\dfrac{5\pi}{2},12).\quad (b)\ (\dfrac{3\pi}{2},-21).\quad (c)(i)\ A=-12.\quad (c)(ii)\ B=\dfrac{5\pi}{4}$.

  1. State the shown tangent asymptote

    The shown dashed asymptote is the right-hand positive asymptote before $2\pi$, so $l$ has equation $x=\dfrac{3\pi}{2}$.

  2. Describe the reciprocal graph

    For $y=\dfrac1x+1$, the vertical asymptote is $x=0$ and the horizontal asymptote is $y=1$. The right branch lies above $y=1$ and the left branch lies below $y=1$.

  3. Count intersections on -2pi to 2pi

    The number of solutions of $\tan x=\dfrac1x+1$ is the number of intersections of the two graphs. From the sketch on $-2\pi\le x\le2\pi$, there are $5$ intersections.

    From the repeated tangent branches and the reciprocal curve, there is one intersection in each positive interval between consecutive tangent asymptotes. From $0$ to $40\pi$, this gives $40$ solutions.

    Extending the same intersection pattern across the stated interval gives $14$ intersections, so there are $14$ solutions.

Final answer

14. WMA11/01 May/June 2022 · Q9

Medium8 marks
Show worked solution
  1. Use sine symmetry

    $\sin(180^\circ-\alpha)=\sin\alpha=p$, so $2\sin(180^\circ-\alpha)=2p$.

  2. Use odd symmetry

    $\sin(\alpha-180^\circ)=-\sin(180^\circ-\alpha)=-p$.

  3. Use the third quadrant identity

    $\sin(180^\circ+\alpha)=-\sin\alpha=-p$, so $3+\sin(180^\circ+\alpha)=3-p$.

  4. Sketch y = sin 2x

    The graph has amplitude 1 and period $180^\circ$. It crosses the x-axis at $0^\circ,90^\circ,180^\circ$, has a maximum at $45^\circ$, and a minimum at $135^\circ$.

  5. Solve sin 2x = p

    Since $\sin\alpha=p$ and $0<2x<360^\circ$, the possible values are $2x=\alpha$ or $2x=180^\circ-\alpha$.

  6. Find x

    Therefore $x=\dfrac{\alpha}{2}$ or $x=90^\circ-\dfrac{\alpha}{2}$.

Final answer

$(a)(i)\ 2p,\ (ii)\ -p,\ (iii)\ 3-p.\quad (c)\ x=\dfrac{\alpha}{2},\ 90^\circ-\dfrac{\alpha}{2}$.

15. WMA11/01 January 2026 · Q9

Hard9 marks
Show worked solution
  1. Identify f(x)

    The graph has amplitude $10$, period $2\pi$, and value $-10$ at $x=0$, so $f(x)=-10\cos x$.

  2. Sketch y equals 10 minus x squared

    The graph $y=10-x^2$ is a downward-opening parabola with vertex $(0,10)$ and x-intercepts at $x=\pm\sqrt{10}$.

  3. Count intersections with the parabola

    On the given sketch, the parabola meets $f(x)$ twice. Outside the central part the parabola is below the range of $f(x)$, so there are $2$ solutions in $-100\pi\le x\le100\pi$.

  4. Sketch y equals tan x

    The graph $y=\tan x$ has zeros at integer multiples of $\pi$ and vertical asymptotes at $x=\dfrac\pi2+n\pi$.

  5. Count in the reference interval

    In $-2\pi\le x\le2\pi$, the graph $y=\tan x$ intersects $f(x)$ four times.

  6. Scale to the required interval

    The interval $-100\pi\le x\le100\pi$ is $50$ times as long as $-2\pi\le x\le2\pi$, so the number of solutions is $50\times4=200$.

Final answer

$(a)\ f(x)=-10\cos x.\quad (b)(ii)\ 2.\quad (c)(ii)\ 200$.

16. WMA11/01 May/June 2023 · Q9

Hard9 marks
Show worked solution
  1. Identify f(x)

    The first graph has amplitude 3, period $2\pi$, and maximum at $x=0$, so $f(x)=3\cos x$.

  2. Transform f

    $y=f\left(x+\dfrac\pi4\right)=3\cos\left(x+\dfrac\pi4\right)$, a shift left by $\dfrac\pi4$.

  3. Find the x-intercepts

    $\cos\left(x+\dfrac\pi4\right)=0$ gives $x=\dfrac\pi4+n\pi$. In $-2\pi<x<2\pi$, these are $-\dfrac{7\pi}{4}$, $-\dfrac{3\pi}{4}$, $\dfrac\pi4$, and $\dfrac{5\pi}{4}$.

  4. Find the y-intercept

    At $x=0$, $y=3\cos\dfrac\pi4=\dfrac{3\sqrt2}{2}$.

  5. Identify g(x)

    The second graph has amplitude 1, period $\pi$, and passes through the origin with positive gradient, so $g(x)=\sin2x$.

  6. Transform g

    $y=g(x)-2=\sin2x-2$, so the graph is shifted down by 2. Its y-intercept is $(0,-2)$.

Final answer

$(i)(a)\ f(x)=3\cos x.\quad (i)(b)$ x-intercepts $-\dfrac{7\pi}{4},-\dfrac{3\pi}{4},\dfrac\pi4,\dfrac{5\pi}{4}$ and y-intercept $\dfrac{3\sqrt2}{2}$. $(ii)(a)\ g(x)=\sin2x.\quad (ii)(b)$ y-intercept $(0,-2)$.

17. WMA11/01 January 2025 · Q9

Hard13 marks
Show worked solution
  1. Complete the square

    $6x-\dfrac{27}{4}-x^2=-(x^2-6x)-\dfrac{27}{4}=-(x-3)^2+9-\dfrac{27}{4}$.

  2. State the completed-square form

    $6x-\dfrac{27}{4}-x^2=\dfrac94-(x-3)^2$.

  3. Find the maximum point

    The maximum point is $P=(3,\dfrac94)$.

  4. Find the x-intercepts of C1

    $\dfrac94-(x-3)^2=0$ gives $x=3\pm\dfrac32$. Hence $A$ has $x=\dfrac32$ and $B$ has $x=\dfrac92$.

  5. Use consecutive zeros of cosine

    The distance between consecutive zeros of $\cos(kx)$ is $\dfrac\pi{k}$.

  6. Find k and the period

    Since $x_B-x_A=\dfrac92-\dfrac32=3$, $\dfrac\pi{k}=3$, so $k=\dfrac\pi3$. The period is $\dfrac{2\pi}{k}=6$.

  7. Find the line through P and B

    The line through $P(3,\dfrac94)$ and $B(\dfrac92,0)$ has gradient $-\dfrac32$, so $L$ is $y=-\dfrac32x+\dfrac{27}{4}$.

  8. Define the x-range

    The region lies between $A$ and $B$, so $\dfrac32\le x\le\dfrac92$.

  9. Define the lower boundary

    The lower boundary is $C_2$, so $y\ge\cos\left(\dfrac\pi3x\right)$.

  10. Define the upper boundaries

    The region is below both $C_1$ and the line segment $L$, so $y\le\dfrac94-(x-3)^2$ and $y\le-\dfrac32x+\dfrac{27}{4}$.

Final answer

$(a)\ \dfrac94-(x-3)^2.\quad (b)\ P=(3,\dfrac94).\quad (c)(i)\ x_B=\dfrac92.\quad (c)(ii)\ k=\dfrac\pi3.\quad (c)(iii)\ 6.\quad (d)\ \dfrac32\le x\le\dfrac92,\ y\ge\cos(\dfrac\pi3x),\ y\le\dfrac94-(x-3)^2,\ y\le-\dfrac32x+\dfrac{27}{4}$.
