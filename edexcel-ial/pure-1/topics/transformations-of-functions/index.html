1. WMA11/01 October 2025 · Q9

Medium6 marks
Show worked solution
  1. Identify amplitude and direction

    The graph has amplitude $4$, crosses the origin, and initially moves downwards, so $f(x)=-4\sin x$.

  2. Identify P

    The labelled maximum is at $P=\left(\dfrac{3\pi}{2},4\right)$.

  3. Translate the graph right

    $y=f\left(x-\dfrac\pi6\right)$ translates the graph right by $\dfrac\pi6$.

  4. New coordinates for part b(i)

    $P$ becomes $\left(\dfrac{3\pi}{2}+\dfrac\pi6,4\right)=\left(\dfrac{5\pi}{3},4\right)$.

  5. Transform y equals negative half f(x)

    $y=-\dfrac12f(x)$ leaves x-coordinates unchanged and multiplies y-coordinates by $-\dfrac12$.

  6. New coordinates for part b(ii)

    $P$ becomes $\left(\dfrac{3\pi}{2},-2\right)$.

Final answer

$(a)\ f(x)=-4\sin x.\quad (b)(i)\ \left(\dfrac{5\pi}{3},4\right).\quad (b)(ii)\ \left(\dfrac{3\pi}{2},-2\right)$.

2. WMA11/01 May/June 2024 · Q3

Medium6 marks
Show worked solution
  1. Read the original key points

    The original curve passes through $(-1,0)$ and $(0,2)$, and touches the x-axis at $(3,0)$.

  2. Translate the graph left

    $y=f(x+3)$ is a translation 3 units left. So $(-1,0)$ moves to $(-4,0)$, $(0,2)$ moves to $(-3,2)$, and $(3,0)$ moves to $(0,0)$.

  3. State the axis intercepts for part a

    The curve cuts the x-axis at $(-4,0)$ and touches it at $(0,0)$. The y-intercept is also $(0,0)$.

  4. Transform y equals f of negative 3x

    For $y=f(-3x)$, a point with original x-coordinate $X$ moves to $x=-\dfrac{X}{3}$.

  5. State the axis intercepts for part b

    $(-1,0)$ moves to $(\dfrac13,0)$, $(3,0)$ moves to $(-1,0)$, and $(0,2)$ stays at $(0,2)$.

Final answer

$(a)$ intercepts $(-4,0)$ and $(0,0)$, with $(0,0)$ a touch point. $(b)$ intercepts $(-1,0)$, $(\dfrac13,0)$ and $(0,2)$, with $(-1,0)$ a touch point.

3. WMA11/01 May/June 2022 · Q4

Medium6 marks
Show worked solution
  1. Translate for y = f(x) - 2

    Subtracting 2 moves every point of the graph down by 2 units.

  2. State the new key features

    The minimum $P(-1,0)$ becomes $(-1,-2)$, the maximum $Q(\frac32,2)$ becomes $(\frac32,0)$, and the asymptote $y=1$ becomes $y=-1$.

  3. Reflect for y = f(-x)

    Replacing $x$ by $-x$ reflects the graph in the y-axis.

  4. State the reflected key features

    The minimum $P(-1,0)$ becomes $(1,0)$, the maximum $Q(\frac32,2)$ becomes $(-\frac32,2)$, and the horizontal asymptote remains $y=1$.

Final answer

$(i)$ minimum $(-1,-2)$, maximum $(\frac32,0)$, asymptote $y=-1$. $(ii)$ minimum $(1,0)$, maximum $(-\frac32,2)$, asymptote $y=1$.

4. WMA11/01 October 2022 · Q7

Medium8 marks
Show worked solution
  1. Read f(x) < 6 from the graph

    The curve is below the line $y=6$ for $x<-4$, for $-1<x<2$, and for $x>3$.

  2. Solve f(2x) = 6

    Since $f(u)=6$ at $u=-4,-1,2,3$, we set $2x=-4,-1,2,3$. The solutions are $x=-2,-\dfrac12,1,\dfrac32$.

  3. State the largest solution

    The largest solution is $x=\dfrac32$.

  4. Reflect the points in the y-axis

    For $y=f(-x)$, each point $(x,y)$ becomes $(-x,y)$.

  5. List the transformed points

    $P(-4,6)\to(4,6)$, $Q(-1,6)\to(1,6)$, $R(2,6)\to(-2,6)$, and $S(3,6)\to(-3,6)$.

  6. Use the reflected graph

    For $x<0$, the part of the reflected graph on or above $y=6$ is from $x=-3$ to $x=-2$.

Final answer

$(a)\ x<-4,\ -1<x<2,\ x>3.\quad (b)\ \dfrac32.\quad (c)(ii)\ -3\le x\le -2$.

5. WMA11/01 October 2021 · Q9

Hard9 marks
Show worked solution
  1. Transform P on y = f(2x)

    $y=f(2x)$ is a horizontal scale factor of $\dfrac12$, so $P(9,3)$ maps to $\left(\dfrac92,3\right)$.

  2. Translate point P

    $y=f(x)+3$ is a translation 3 units upward, so $P(9,3)$ maps to $(9,6)$.

  3. Set up the intersection equation

    At $Q$, $f(2x)=f(x)+3$. Since $f(x)=\sqrt{x}$, this gives $\sqrt{2x}=\sqrt{x}+3$.

  4. Show the required equation

    Let $s=\sqrt{x}$. Then $\sqrt{2x}=\sqrt2\,s$, so $\sqrt2s=s+3$. Hence $(\sqrt2-1)s=3$ and $s=\dfrac3{\sqrt2-1}=3(\sqrt2+1)$.

  5. Find the x-coordinate

    $\sqrt{x}=3(\sqrt2+1)$, so $x=9(\sqrt2+1)^2=9(3+2\sqrt2)=27+18\sqrt2$.

  6. Find the y-coordinate

    $y=\sqrt{x}+3=3(\sqrt2+1)+3=6+3\sqrt2$. Therefore $Q=(27+18\sqrt2,\ 6+3\sqrt2)$.

Final answer

$(a)\ P\mapsto\left(\dfrac92,3\right)\text{ on }y=f(2x),\ P\mapsto(9,6)\text{ on }y=f(x)+3.\quad (c)\ Q=(27+18\sqrt2,\ 6+3\sqrt2)$.

6. WMA11/01 May/June 2025 · Q9

Hard10 marks
Show worked solution
  1. Transform y equals root x to C1

    $C_1$ has equation $y=\sqrt{2x}$. This is obtained from $y=\sqrt{x}$ by a stretch parallel to the x-axis with scale factor $\dfrac12$.

  2. Equivalent description

    Equivalently, $y=\sqrt{2x}=\sqrt2\sqrt{x}$ is a stretch parallel to the y-axis with scale factor $\sqrt2$. The mark scheme also accepts the horizontal stretch description.

  3. Translate the reflected curve

    $C_2$ has equation $y=12-\sqrt{x}=-\sqrt{x}+12$, so it is a translation of $y=-\sqrt{x}$ by $\begin{pmatrix}0\\12\end{pmatrix}$.

  4. Set the curves equal

    At $P$, $\sqrt{2x}=12-\sqrt{x}$.

  5. Factor out root x

    $\sqrt2\sqrt{x}+\sqrt{x}=12$, so $(\sqrt2+1)\sqrt{x}=12$.

  6. Rationalise

    $\sqrt{x}=\dfrac{12}{\sqrt2+1}=\dfrac{12(\sqrt2-1)}{(\sqrt2+1)(\sqrt2-1)}=12(\sqrt2-1)$.

  7. Find x

    $x=[12(\sqrt2-1)]^2=144(3-2\sqrt2)$.

  8. Find y

    $y=\sqrt{2x}=\sqrt2\sqrt{x}=\sqrt2\cdot12(\sqrt2-1)=24-12\sqrt2$.

Final answer

$(a)(i)$ stretch parallel to the x-axis scale factor $\dfrac12$ (equivalently vertical stretch scale factor $\sqrt2$). $(a)(ii)$ translation by $\begin{pmatrix}0\\12\end{pmatrix}$. $(b)\ P=(144(3-2\sqrt2),\ 24-12\sqrt2)$.

7. WMA11/01 January 2023 · Q7

Hard10 marks
Show worked solution
  1. Sketch y = 6/x

    The graph is a rectangular hyperbola with asymptotes $x=0$ and $y=0$, with branches in quadrants I and III.

  2. Describe the transformation

    $y=\dfrac6{x-2}$ is obtained from $y=\dfrac6x$ by a translation 2 units in the positive x-direction.

  3. Use P to find k

    At $x=-4$ on $y=\dfrac6{x-2}$, $y=\dfrac6{-6}=-1$.

  4. Substitute into the line

    Since $P$ lies on $y=kx+7$, $-1=-4k+7$, so $k=2$.

  5. Find the second intersection

    Solve $\dfrac6{x-2}=2x+7$. Multiplying by $x-2$ gives $6=(2x+7)(x-2)$.

  6. Factor and choose Q

    $6=2x^2+3x-14$, so $2x^2+3x-20=0=(2x-5)(x+4)$. The root $x=-4$ is $P$, so $Q$ has $x=\dfrac52$.

  7. Find y for Q

    $y=2\left(\dfrac52\right)+7=12$, so $Q=\left(\dfrac52,12\right)$.

Final answer

$(b)$ Translation 2 units right. $(c)\ k=2.\quad (d)\ Q=\left(\dfrac52,12\right)$.
