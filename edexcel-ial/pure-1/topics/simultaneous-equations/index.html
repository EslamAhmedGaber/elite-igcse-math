1. WMA11/01 January 2025 · Q3

Easy5 marks
Show worked solution
  1. Use t equals 5

    The population is $58$ thousand, so $58^2=a+b(5^3)$, giving $3364=a+125b$.

  2. Use t equals 10

    The population is $65$ thousand, so $65^2=a+b(10^3)$, giving $4225=a+1000b$.

  3. Solve for b

    Subtracting gives $861=875b$, so $b=\dfrac{861}{875}=\dfrac{123}{125}$.

  4. Solve for a

    $a=3364-125\left(\dfrac{123}{125}\right)=3241$.

  5. Use population 85 thousand

    $85^2=3241+\dfrac{123}{125}T^3$.

  6. Find T

    $T^3=\dfrac{125(7225-3241)}{123}$, so $T\approx15.938$ and $T=15.9$ to one decimal place.

Final answer

$(a)\ a=3241,\ b=\dfrac{123}{125}.\quad (b)\ T=15.9$ years.

2. WMA11/01 January 2026 · Q2

Easy6 marks
Show worked solution
  1. Use the linear equation

    $y-x=4$, so $y=x+4$.

  2. Substitute into the second equation

    $2x^2-xy=8$ becomes $2x^2-x(x+4)=8$.

  3. Show the quadratic

    $2x^2-x^2-4x=8$, so $x^2-4x-8=0$.

  4. Complete the square

    $x^2-4x-8=0$ gives $(x-2)^2=12$.

  5. Find x

    $x=2\pm\sqrt{12}=2\pm2\sqrt3$.

  6. Find y

    Since $y=x+4$, $y=6\pm2\sqrt3$ with matching signs.

  7. State both solutions

    $(x,y)=(2+2\sqrt3,6+2\sqrt3)$ or $(2-2\sqrt3,6-2\sqrt3)$.

Final answer

$(x,y)=(2+2\sqrt3,\ 6+2\sqrt3)$ or $(2-2\sqrt3,\ 6-2\sqrt3)$.

3. WMA11/01 October 2023 · Q8

Medium7 marks
Show worked solution
  1. Write C1 in terms of y

    $xy=\dfrac{15}{2}-5x$, so $y=\dfrac{15}{2x}-5$.

  2. Equate the two curves

    $\dfrac{15}{2x}-5=x^3-\dfrac72x-5$.

  3. Multiply by 2x

    $15=2x^4-7x^2$, hence $2x^4-7x^2-15=0$.

  4. Solve for x

    Let $u=x^2$. Then $2u^2-7u-15=0=(2u+3)(u-5)$, so $x^2=5$ and $x=\pm\sqrt5$.

  5. Find the y-coordinates

    Using $y=\dfrac{15}{2x}-5$, the points are $\left(\sqrt5,\dfrac{3\sqrt5}{2}-5\right)$ and $\left(-\sqrt5,-\dfrac{3\sqrt5}{2}-5\right)$.

  6. Use the distance formula

    $\Delta x=2\sqrt5$ and $\Delta y=3\sqrt5$, so $PQ=\sqrt{(2\sqrt5)^2+(3\sqrt5)^2}=\sqrt{65}$.

Final answer

$(a)\ 2x^4-7x^2-15=0.\quad (b)\ PQ=\sqrt{65}$.
