1. WMA13/01 October 2023 · Q1

  1. Part (a)

    The function $f(x)=x^2-5x+e^x$ is continuous on $[1,2]$.

    \[f(1)=e-4=-1.2817\ldots\lt 0,\qquad f(2)=e^2-6=1.3891\ldots\gt 0.\]

    Since the endpoint values have opposite signs, there is a root strictly between 1 and 2.

    \[\boxed{1\lt \alpha\lt 2}\]
  2. Part (b)

    Using the given iteration with $x_1=1$,

    \[x_2=\sqrt{5-e}=1.5105357\ldots.\]

    Continue with unrounded values:

    \[x_3=1.7388278\ldots,\quad x_4=1.7330522\ldots,\quad x_5=1.7341754\ldots,\quad x_6=1.7339613\ldots.\]

    Subsequent iterates are $1.7340023\ldots,1.7339945\ldots,1.7339960\ldots$, which settle to $1.7339957\ldots$. Thus (i) $x_2=1.5105$ and (ii) $\alpha=1.7340$, each to 4 decimal places.

    \[\boxed{x_2=1.5105,\qquad\alpha=1.7340}\]
Final answer

(a) $1\lt \alpha\lt 2$ (b) $x_2=1.5105,\qquad\alpha=1.7340$

  1. Part (a)

    Work in radians. Substituting the endpoints into $f(x)=2\sec x+6x-3$ gives

    \[f(0.1)=-0.3899581632\ldots\lt 0,\qquad f(0.2)=0.2406776899\ldots\gt 0.\]

    The function is continuous on $[0.1,0.2]$ since $\cos x\ne0$ there. The sign change therefore places a root between the endpoints. Since the given root is unique, this root is $\alpha$.

    \[\boxed{0.1\lt \alpha\lt 0.2}\]
  2. Part (b)

    Set $f(x)=0$ and use $\sec x=1/\cos x$:

    \[\frac{2}{\cos x}+6x-3=0 \ \Longrightarrow\ 6x=3-\frac{2}{\cos x} \ \Longrightarrow\ x=\frac12-\frac{1}{3\cos x}.\]

    Thus $\alpha$, which satisfies $f(\alpha)=0$, satisfies this rearranged equation.

    \[\boxed{x=\frac12-\frac{1}{3\cos x}}\]
  3. Part (c)(i)

    With $x_1=0.15$ and angles in radians,

    \[x_2=\frac12-\frac{1}{3\cos(0.15)}=0.1628811858\ldots.\]

    Round only the displayed result to four decimal places.

    \[\boxed{x_2=0.1629}\]
  4. Part (c)(ii)

    Continuing the iteration with unrounded internal values gives

    \[x_3=0.1621955413\ldots,\quad x_4=0.1622335203\ldots,\quad x_5=0.1622314210\ldots,\quad x_6=0.1622315370\ldots.\]

    The iterates settle at $0.16223153\ldots$, giving the root to four decimal places.

    \[\boxed{\alpha=0.1622}\]
Final answer

(a) $0.1\lt \alpha\lt 0.2$ (b) $x=\frac12-\frac{1}{3\cos x}$ (c)(i) $x_2=0.1629$ (c)(ii) $\alpha=0.1622$

  1. Part (a)

    Differentiate $y=(3+4e^{x^2})^{1/2}$ using the chain rule:

    \[\frac{dy}{dx}=\frac12(3+4e^{x^2})^{-1/2}\cdot4e^{x^2}\cdot2x =\frac{4xe^{x^2}}{\sqrt{3+4e^{x^2}}}.\]
    \[\boxed{\frac{dy}{dx}=\frac{4xe^{x^2}}{\sqrt{3+4e^{x^2}}}}\]
  2. Part (b)

    Since the tangent at $P=(\alpha,\sqrt{3+4e^{\alpha^2}})$ passes through the origin, its gradient is $y_P/\alpha$, with $\alpha\gt 0$. Equate this to the derivative:

    \[\frac{4\alpha e^{\alpha^2}}{\sqrt{3+4e^{\alpha^2}}} =\frac{\sqrt{3+4e^{\alpha^2}}}{\alpha} \quad\Longrightarrow\quad4\alpha^2e^{\alpha^2}=3+4e^{\alpha^2}.\]

    Consequently $x=\alpha$ solves the displayed equation.

    \[\boxed{4x^2e^{x^2}-4e^{x^2}-3=0}\]
  3. Part (c)

    Let $h(x)=4x^2e^{x^2}-4e^{x^2}-3$, a continuous function. Then $h(1)=-3\lt 0$ and $h(2)=12e^4-3=652.1778\ldots\gt 0$, so a root lies between 1 and 2. Moreover $h'(x)=8x^3e^{x^2}\gt 0$ for $x\gt 0$, so this is the unique positive root corresponding to the tangent abscissa $\alpha$.

    \[\boxed{1\lt \alpha\lt 2}\]
  4. Part (d)

    From $4x^2e^{x^2}=4e^{x^2}+3$, divide by the positive $e^{x^2}$ to get $4x^2=4+3e^{-x^2}$. The source domain has $x\ge0$, so take the positive square root.

    \[\boxed{x=\frac12\sqrt{4+3e^{-x^2}}}\]
  5. Part (e)

    With $x_1=1$, the unrounded iterates start

    \[x_2=1.1295616764\ldots,\quad x_3=1.0997193683\ldots,\quad x_4=1.1062486441\ldots,\quad x_5=1.1048012899\ldots.\]

    Continue: $x_6=1.1051212304\ldots$, $x_7=1.1050504628\ldots$, $x_8=1.1050661137\ldots$, $x_9=1.1050626523\ldots$; further iteration settles at $1.1050632792\ldots$. Therefore (i) $x_3=1.0997$ and (ii) $\alpha=1.1051$, both to four decimal places.

    \[\boxed{x_3=1.0997,\qquad\alpha=1.1051}\]
Final answer

(a) $\frac{dy}{dx}=\frac{4xe^{x^2}}{\sqrt{3+4e^{x^2}}}$ (b) $4x^2e^{x^2}-4e^{x^2}-3=0$ (c) $1\lt \alpha\lt 2$ (d) $x=\frac12\sqrt{4+3e^{-x^2}}$ (e) $x_3=1.0997,\qquad\alpha=1.1051$

  2. Part (b)

  1. Part (a)

    Let $f(x)=2\cos3x-3x+4$, using radians. Then

    \[\begin{aligned} f(0.8)&=2\cos2.4-2.4+4=0.1252125\ldots\gt 0,\\ f(0.9)&=2\cos2.7-2.7+4=-0.5081443\ldots\lt 0. \end{aligned}\]

    The function is continuous on $[0.8,0.9]$, so this change of sign shows that there is a root between the endpoints. Moreover, $f'(x)=-6\sin3x-3\lt 0$ on this interval, so this root is unique there. Thus the crossing shown at $P$ has $\boxed{0.8\lt \alpha\lt 0.9}$.

  2. Part (b)(i)

    Using the inverse cosine in radians,

    \[x_2=\frac13\arccos(1.5(0.8)-2) =\frac13\arccos(-0.8)=0.8326971\ldots.\]

    Hence $\boxed{x_2=0.8327}$ to 4 decimal places.

  3. Part (b)(ii)

    Continue the iteration, retaining the full calculator values at each step:

    \[\begin{aligned} x_3&=\frac13\arccos(1.5x_2-2)=0.8067674\ldots,\\ x_4&=\frac13\arccos(1.5x_3-2)=0.8271196\ldots,\\ x_5&=\frac13\arccos(1.5x_4-2)=0.8110216\ldots. \end{aligned}\]

    Therefore $\boxed{x_5=0.8110}$ to 4 decimal places.

  4. Part (c)

    Differentiate the curve equation:

    \[\frac{dy}{dx}=-6\sin3x-3, \qquad \frac{d^2y}{dx^2}=-18\cos3x.\]

    At a stationary point,

    \[-6\sin3x-3=0 \quad\Longrightarrow\quad \sin3x=-\frac12.\]

    For $x\gt 0$, the stationary points therefore belong to the two families

    \[3x=\frac{7\pi}{6}+2n\pi \quad\text{or}\quad 3x=\frac{11\pi}{6}+2n\pi, \qquad n=0,1,2,\ldots.\]

    In the first family, $\cos3x=-\frac{\sqrt3}{2}$, giving $y”=9\sqrt3\gt 0$, so these are local minima. In the second family, $\cos3x=\frac{\sqrt3}{2}$ and $y”=-9\sqrt3\lt 0$, so these are local maxima and are excluded. Thus all positive minimum coordinates are

    \[x=\frac{7\pi}{18}+\frac{2n\pi}{3},\qquad n=0,1,2,\ldots.\]

    The two smallest are obtained with $n=0$ and $n=1$:

    \[\boxed{\beta=\frac{7\pi}{18}}, \qquad \boxed{\lambda=\frac{19\pi}{18}}.\]
Final answer
