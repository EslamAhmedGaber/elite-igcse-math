2. WMA13/01 May/June 2025 · Q5

Easy4 marks
Show worked solution
  1. Part (i)

    Use $\sin^2(3x)=(1-\cos6x)/2$:

    \[\int\sin^2(3x)\,dx=\frac12\int(1-\cos6x)\,dx =\boxed{\frac{x}{2}-\frac{\sin6x}{12}+C}.\]
  2. Part (ii)

    The derivative of $(x^2+4)^{5/2}$ is $5x(x^2+4)^{3/2}$. Therefore

    \[\int x(x^2+4)^{3/2}\,dx=\boxed{\frac15(x^2+4)^{5/2}+C}.\]

    For example, differentiating this answer gives

    \[\frac15\cdot\frac52(x^2+4)^{3/2}\cdot2x=x(x^2+4)^{3/2},\]

    which recovers the integrand. Each indefinite integral has its own arbitrary constant.

Final answer

(i) $\frac{x}{2}-\frac{\sin6x}{12}+C$ (ii) $\frac15(x^2+4)^{5/2}+C$

  1. Part (a)

    Apply the cosine addition formula:

    \[\cos2A=\cos(A+A)=\cos A\cos A-\sin A\sin A =\cos^2 A-\sin^2 A.\]

    Using $\sin^2 A=1-\cos^2 A$ gives the required identity.

    \[\boxed{\cos2A=2\cos^2 A-1}\]

    \[\frac{3\pi}{8}-\frac{\sqrt2}{6}-\left(\frac\pi4-\frac13\right).\]
    \[\boxed{\frac\pi8+\frac13-\frac{\sqrt2}{6}}\]

    \[\frac{dy}{dx}=\frac{1}{2x^2+5}(4x)=\frac{4x}{2x^2+5}.\]

    \[\int\frac{2}{3x-1}\,dx=\frac23\ln(3x-1)+K.\]

    \[\begin{aligned} \int_3^{42}\frac{2}{3x-1}\,dx &=\left[\frac23\ln(3x-1)\right]_3^{42}\\ &=\frac23\bigl(\ln125-\ln8\bigr)\\ &=\frac23\ln\left(\frac{125}{8}\right) =\frac23\ln\left(\left(\frac52\right)^3\right). \end{aligned}\]

    Using $\ln(a^3)=3\ln a$ for $a\gt 0$, the exact value in simplest form is

    \[\boxed{2\ln\left(\frac52\right).}\]
  2. Part (ii)

    Multiply the given decomposition by $(x-1)^2$:

    \[\begin{aligned} 2x^3-7x^2+8x+1 &=(Ax+B)(x-1)^2+C\\ &=Ax^3+(B-2A)x^2+(A-2B)x+(B+C). \end{aligned}\]

    Comparing coefficients gives

    \[A=2,\qquad B-2A=-7\ \Longrightarrow\ B=-3, \qquad B+C=1\ \Longrightarrow\ C=4.\]

    The coefficient of $x$ also agrees, since $A-2B=2-2(-3)=8$. Hence

    \[\boxed{A=2,\qquad B=-3,\qquad C=4,} \qquad h(x)=2x-3+4(x-1)^{-2}.\]

    Integrating each term,

Final answer
