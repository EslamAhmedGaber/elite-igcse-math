1. WMA12/01 October 2019 · Q1

Easy6 marks
Show worked solution
  1. Expand the curve

    $y=2x^2(x-5)=2x^3-10x^2$.

  2. Differentiate

    $\dfrac{dy}{dx}=6x^2-20x=2x(3x-10)$.

  3. Find the stationary values of x

    At a stationary point, $\dfrac{dy}{dx}=0$. Hence $2x(3x-10)=0$, so $x=0$ or $x=\dfrac{10}{3}$.

  4. Use the sign of the derivative

    Since $2x(3x-10)$ is positive outside its two roots and negative between them, $y$ is increasing for $x<0$ and for $x>\dfrac{10}{3}$.

Final answer

$(a)\ x=0,\ \dfrac{10}{3}.\quad (b)\ x<0\text{ or }x>\dfrac{10}{3}$.

2. WMA12/01 October 2024 · Q4

Medium7 marks
Show worked solution
  1. Rewrite using powers

    $y=4x^{1/2}+9x^{-1/2}+3$.

  2. Differentiate

    $\dfrac{dy}{dx}=2x^{-1/2}-\dfrac92x^{-3/2}=\dfrac{2}{\sqrt{x}}-\dfrac{9}{2x^{3/2}}$.

  3. Set the derivative to zero

    $\dfrac{dy}{dx}=\dfrac{4x-9}{2x^{3/2}}$. Since $x>0$, the stationary point occurs when $4x-9=0$.

  4. Find the x coordinate

    Therefore $x=\dfrac94$.

  5. Differentiate again

    $\dfrac{d^2y}{dx^2}=-x^{-3/2}+\dfrac{27}{4}x^{-5/2}=-\dfrac1{x^{3/2}}+\dfrac{27}{4x^{5/2}}$.

  6. Test the stationary point

    $\dfrac{d^2y}{dx^2}=\dfrac{27-4x}{4x^{5/2}}$. At $x=\dfrac94$, the numerator is $27-9=18>0$, so the stationary point is a minimum.

  7. Find where y is decreasing

    For $x>0$, $2x^{3/2}>0$, so $\dfrac{dy}{dx}<0$ when $4x-9<0$. Hence $y$ is decreasing for $0<x<\dfrac94$.

Final answer

$(a)$ $\dfrac{2}{\sqrt{x}}-\dfrac{9}{2x^{3/2}}$. $\quad (b)$ $x=\dfrac94$. $\quad (c)(i)$ $-\dfrac1{x^{3/2}}+\dfrac{27}{4x^{5/2}}$. $\quad (c)(ii)$ Minimum. $\quad (d)$ $0<x<\dfrac94$.

4. WMA12/01 October 2022 · Q2

Medium7 marks · main topic: Binomial Expansion
Show worked solution
  1. Use the remainder theorem

    Dividing by $4x-5$ means the remainder is $f\left(\dfrac54\right)$.

  2. Substitute x equals five quarters

    $f\left(\dfrac54\right)=\left(2-\dfrac{5k}{4}\right)^5=\dfrac{243}{32}$.

  3. Take the fifth root

    Since $\dfrac{243}{32}=\left(\dfrac32\right)^5$, we have $2-\dfrac{5k}{4}=\dfrac32$.

  4. Find k

    $\dfrac{5k}{4}=\dfrac12$, so $k=\dfrac25$.

  5. Expand the binomial

    With $k=\dfrac25$, $f(x)=\left(2-\dfrac25x\right)^5$.

  6. Find the first three terms

    $2^5+5(2^4)\left(-\dfrac25x\right)+10(2^3)\left(-\dfrac25x\right)^2=32-32x+\dfrac{64}{5}x^2$.

  7. Use the coefficient of x

    For a polynomial, the gradient at $x=0$ is the coefficient of $x$ in the expansion. Therefore $f'(0)=-32$.

Final answer

$(a)$ $k=\dfrac25$. $\quad (b)\ 32-32x+\dfrac{64}{5}x^2$. $\quad (c)\ -32$.

6. WMA12/01 May/June 2021 · Q6

  1. Complete the square

    $x^2-6x=(x-3)^2-9$ and $y^2+8y=(y+4)^2-16$.

  2. Write centre-radius form

    The circle becomes $(x-3)^2+(y+4)^2=25-k$.

  3. Use the tangent condition

    The centre is $(3,-4)$. Since the $x$-axis is tangent, the radius is the distance from the centre to the $x$-axis, which is $4$.

  4. Find k

    Thus $25-k=4^2=16$, so $k=9$.

  5. Find the intercepts

    With $k=9$, the circle is $(x-3)^2+(y+4)^2=16$. On the $x$-axis, $y=0$, giving $x=3$.

  6. Find the y-axis points

    On the $y$-axis, $x=0$, so $9+(y+4)^2=16$. Hence $y=-4\pm\sqrt7$.

  7. Calculate the triangle area

    The vertical base on the $y$-axis has length $2\sqrt7$, and its perpendicular distance to $(3,0)$ is $3$. The area is $\dfrac12(2\sqrt7)(3)=3\sqrt7$.

    Substitute $(2,5)$ into $y=ax^3-3x^2+3x+b$: $5=8a-12+6+b$, so $8a+b=11$.

9. WMA12/01 January 2026 · Q6

Show worked solution
  1. Represent the consecutive odd numbers

    Let $q=2n-1$ and $p=2n+1$, where $n$ is a positive integer. Then $p>q>0$ and the numbers are consecutive odd numbers.

  2. Subtract the squares

    $p^2-q^2=(2n+1)^2-(2n-1)^2$.

  3. Simplify the expression

    $p^2-q^2=(4n^2+4n+1)-(4n^2-4n+1)=8n$.

  4. Conclude the proof

    Since $n$ is an integer, $8n$ is a multiple of $8$, so $p^2-q^2$ is a multiple of $8$.

  5. Differentiate the curve

    For $y=x^3+12x^2+49x+2$, $\dfrac{dy}{dx}=3x^2+24x+49$.

  6. Show the gradient is never zero

    $3x^2+24x+49=3(x+4)^2+1$. This is always positive for real $x$.

  7. State the conclusion

    Since $\dfrac{dy}{dx}$ is never $0$, the curve has no stationary points.

Final answer

$(i)$ Proven. $\quad (ii)$ $C$ has no stationary points.

  1. Rewrite the curve

    $y=\dfrac{\sqrt{x}(100-x^2)}{40}=\dfrac52x^{1/2}-\dfrac1{40}x^{5/2}$.

  2. Differentiate

    $\dfrac{dy}{dx}=\dfrac54x^{-1/2}-\dfrac1{16}x^{3/2}$.

  3. Use the stationary point

    At $P$, $\dfrac{dy}{dx}=0$. Thus $\dfrac54x^{-1/2}=\dfrac1{16}x^{3/2}$. Multiplying by $16x^{1/2}$ gives $20=x^2$.

  4. Find the x-coordinate

    Since $x\geq0$, $x=\sqrt{20}=2\sqrt5$.

  5. Integrate the curve

    $\int y\,dx=\int\left(\dfrac52x^{1/2}-\dfrac1{40}x^{5/2}\right)dx=\dfrac53x^{3/2}-\dfrac1{140}x^{7/2}$.

  6. Use equal areas

    The signed area from $0$ to $k$ is zero because the positive area $R_1$ equals the negative area $R_2$ in magnitude.

  7. Solve for k

    $\dfrac53k^{3/2}-\dfrac1{140}k^{7/2}=0$. Since $k>0$, divide by $k^{3/2}$ to get $\dfrac53-\dfrac{k^2}{140}=0$, so $k^2=\dfrac{700}{3}$.

  8. Write the exact value

    $k=\sqrt{\dfrac{700}{3}}=\dfrac{10\sqrt{21}}{3}$.

  2. Differentiate

    $x^{3/2}>\dfrac{27}{8}=\left(\dfrac32\right)^3$, so $\sqrt{x}>\dfrac32$ and $x>\dfrac94$.

  5. Find the tangent gradient

    At $P(9,40)$, $\dfrac{dy}{dx}=\dfrac43(9)-\dfrac{9}{2\cdot3}=12-\dfrac32=\dfrac{21}{2}$.

  6. Write the tangent line

    $y-40=\dfrac{21}{2}(x-9)$, so $y=\dfrac{21}{2}x-\dfrac{109}{2}$.

  7. Find where the tangent meets the x-axis

    Set $y=0$: $\dfrac{21}{2}x-\dfrac{109}{2}=0$, so $x=\dfrac{109}{21}$.

  8. Split the area

    From $x=0$ to $x=\dfrac{109}{21}$, the lower boundary is the $x$-axis. From $x=\dfrac{109}{21}$ to $x=9$, the lower boundary is the tangent.

  9. Set up the integral

    $\displaystyle R=\int_0^{109/21}\left(\dfrac23x^2-9\sqrt{x}+13\right)dx+\int_{109/21}^{9}\left(\dfrac23x^2-9\sqrt{x}+13-\left(\dfrac{21}{2}x-\dfrac{109}{2}\right)\right)dx$.

  10. Use antiderivatives

    $\displaystyle \int\left(\dfrac23x^2-9\sqrt{x}+13\right)dx=\dfrac{2}{9}x^3-6x^{3/2}+13x$, and $\displaystyle \int\left(\dfrac{21}{2}x-\dfrac{109}{2}\right)dx=\dfrac{21}{4}x^2-\dfrac{109}{2}x$.

  11. Evaluate

    Substituting the limits and simplifying gives $R=\dfrac{857}{21}$.

Final answer

$(a)$ $y$ is increasing for $x>\dfrac94$. $\quad (b)$ Area $=\dfrac{857}{21}$.

  1. Differentiate the cubic

    For $y=x^3-5x^2+3x+14$, $\dfrac{dy}{dx}=3x^2-10x+3$.

  2. Find stationary x values

    $3x^2-10x+3=0$ factors as $(3x-1)(x-3)=0$, so $x=\dfrac13$ or $x=3$.

  3. Identify the minimum

    $\dfrac{d^2y}{dx^2}=6x-10$. At $x=3$, this is positive, so the minimum turning point has $x=3$.

  4. Find T

    Substitute $x=3$: $y=27-45+9+14=5$. Hence $T=(3,5)$.

  5. Find A

    At $x=2$ on $C_1$, $y=8-20+6+14=8$, so $A=(2,8)$.

  6. Find the circle radius

    The centre of $C_2$ is $T=(3,5)$ and it passes through $A=(2,8)$. Thus $r^2=(2-3)^2+(8-5)^2=10$.

  7. Write the circle equation

    Therefore $C_2$ has equation $(x-3)^2+(y-5)^2=10$.

  8. Find the tangent gradient

    The radius $TA$ has gradient $\dfrac{8-5}{2-3}=-3$, so the tangent at $A$ has gradient $\dfrac13$.

  9. Write the tangent equation

    Using $A=(2,8)$, $y-8=\dfrac13(x-2)$, so $y=\dfrac13x+\dfrac{22}{3}$.

  10. Set up the area

    From $x=0$ to $x=2$, the cubic is above the line. The required area is $\displaystyle \int_0^2 \left[x^3-5x^2+3x+14-\left(\dfrac13x+\dfrac{22}{3}\right)\right]dx$.

  11. Simplify the integrand

    The integrand is $x^3-5x^2+\dfrac83x+\dfrac{20}{3}$.

  12. Integrate

    $\displaystyle \left[\dfrac{x^4}{4}-\dfrac{5x^3}{3}+\dfrac{4x^2}{3}+\dfrac{20x}{3}\right]_0^2=4-\dfrac{40}{3}+\dfrac{16}{3}+\dfrac{40}{3}=\dfrac{28}{3}$.

Final answer

$(a)$ $T=(3,5)$. $\quad (b)$ $(x-3)^2+(y-5)^2=10$. $\quad (c)$ $y=\dfrac13x+\dfrac{22}{3}$. $\quad (d)$ $\dfrac{28}{3}$.
