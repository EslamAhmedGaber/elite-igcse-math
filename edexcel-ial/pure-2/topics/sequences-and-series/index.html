8. WMA12/01 January 2023 · Q4

Medium6 marks · main topic: Laws of Logarithms
Show worked solution
  1. Rewrite the constant

    Since $2=\log_3 9$, the equation becomes $\log_3(4x)+\log_3 9=\log_3(5x+7)$.

  2. Combine the logarithms

    $\log_3(4x)+\log_3 9=\log_3(36x)$.

  3. Solve for x

    Therefore $36x=5x+7$, so $31x=7$ and $x=\dfrac{7}{31}$.

  4. Introduce L

    Let $L=\log_a y$. Then $\log_a(y^r)=r\log_a y=rL$.

  5. Evaluate the left sum

    $\displaystyle \sum_{r=1}^{2}\log_a(y^r)=L+2L=3L$.

  6. Evaluate the right sum

    $\displaystyle \sum_{r=1}^{2}(\log_a y)^r=L+L^2$.

  7. Solve for L

    So $3L=L+L^2$, which gives $L^2-2L=0$ and $L(L-2)=0$.

  8. Use the restrictions

    Since $a>1$ and $y>1$, $\log_a y>0$, so $L\ne0$. Hence $L=2$ and $y=a^2$.

Final answer

$(i)$ $x=\dfrac{7}{31}$. $\quad (ii)$ $y=a^2$.

10. WMA12/01 May/June 2024 · Q2

Medium7 marks · main topic: Arithmetic Sequences
Show worked solution
  1. Use the sixth term

    For an arithmetic series, $u_6=a+5d=2$.

  2. Use the sum of ten terms

    $S_{10}=\dfrac{10}{2}(2a+9d)=-80$, so $2a+9d=-16$.

  3. Solve simultaneously

    From $a+5d=2$, $a=2-5d$. Substitute into $2a+9d=-16$.

  4. Find a and d

    $2(2-5d)+9d=-16$, so $4-d=-16$ and $d=20$. Then $a=2-5(20)=-98$.

  5. Write S n

    $S_n=\dfrac n2(2a+(n-1)d)=\dfrac n2(-196+20n-20)=10n^2-108n$.

  6. Set up the inequality

    We need $10n^2-108n>8000$.

  7. Solve the boundary

    $10n^2-108n-8000=0$ gives $5n^2-54n-4000=0$.

  8. Find the positive threshold

    $n=\dfrac{54+\sqrt{82916}}{10}=34.195\ldots$.

  9. Choose the smallest integer

    Therefore the smallest integer value with $S_n>8000$ is $n=35$.

Final answer

$(a)$ First term $=-98$, common difference $=20$. $\quad (b)$ $n=35$.

12. WMA12/01 January 2023 · Q7

Medium7 marks · main topic: Geometric Sequences
Show worked solution
  1. Write the given terms

    For a geometric sequence, the third term is $ar^2=20$ and the fifth term is $ar^4=12.8$.

  2. Divide the equations

    $\dfrac{ar^4}{ar^2}=\dfrac{12.8}{20}$, so $r^2=0.64$.

  3. Use r positive

    Since $r>0$, $r=0.8$.

  4. Find a

    Using $ar^2=20$, $a(0.8)^2=20$, so $a=\dfrac{20}{0.64}=31.25$.

  5. Write the sum formula

    $S_n=\dfrac{a(1-r^n)}{1-r}=\dfrac{31.25(1-0.8^n)}{0.2}=156.25(1-0.8^n)$.

  6. Set up the inequality

    We need $156.25(1-0.8^n)>156$.

  7. Isolate the power

    $1-0.8^n>\dfrac{156}{156.25}=\dfrac{624}{625}$, so $0.8^n<\dfrac{1}{625}$.

  8. Use logarithms

    $n\log(0.8)<\log\left(\dfrac{1}{625}\right)$. Since $\log(0.8)<0$, dividing reverses the inequality: $n>\dfrac{\log(1/625)}{\log(0.8)}=28.85\ldots$.

  9. Choose the smallest integer

    The smallest possible integer value is therefore $n=29$.

Final answer

$(a)$ $r=0.8$. $\quad (b)$ $a=31.25$. $\quad (c)$ $n=29$.

13. WMA12/01 October 2022 · Q3

  1. Find the first term

    $a_1=\cos^2\left(\dfrac{\pi}{3}\right)=\left(\dfrac12\right)^2=\dfrac14$.

  2. Find the second term

    $a_2=\cos^2\left(\dfrac{2\pi}{3}\right)=\left(-\dfrac12\right)^2=\dfrac14$.

  3. Find the third term

    $a_3=\cos^2(\pi)=(-1)^2=1$.

  4. Recognise the repeating pattern

    The values of $\cos^2\left(\dfrac{n\pi}{3}\right)$ repeat every 3 terms as $\dfrac14,\dfrac14,1$.

  5. Sum the n part

    $\sum_{n=1}^{50} n=\dfrac{50\cdot51}{2}=1275$.

  6. Sum the cosine part

    There are $16$ complete groups of 3 terms in the first $48$ terms, then the first 2 terms repeat. Hence the cosine-square sum is $16\left(\dfrac14+\dfrac14+1\right)+\dfrac14+\dfrac14=24+\dfrac12=\dfrac{49}{2}$.

  7. Add the two sums

    $\sum_{n=1}^{50}\left(n+\cos^2\left(\dfrac{n\pi}{3}\right)\right)=1275+\dfrac{49}{2}=\dfrac{2599}{2}$.

Final answer

$(a)\ a_1=\dfrac14,\ a_2=\dfrac14,\ a_3=1. $\quad $(b)\ \dfrac{2599}{2}$.

16. WMA12/01 January 2020 · Q8

Show worked solution
  1. Write the series forwards

    $S_n=a+(a+d)+(a+2d)+\cdots+(a+(n-1)d)$.

  2. Write the series backwards

    $S_n=(a+(n-1)d)+(a+(n-2)d)+\cdots+a$.

  3. Add the two forms

    Each pair adds to $2a+(n-1)d$, and there are $n$ pairs. Hence $2S_n=n\{2a+(n-1)d\}$.

  4. Complete the proof

    Dividing by $2$ gives $S_n=\dfrac n2\{2a+(n-1)d\}$.

  5. Find u5

    $u_5=5(5)+3(-1)^5=25-3=22$.

  6. Sum the sequence

    $\sum_{n=1}^{59}u_n=5\sum_{n=1}^{59}n+3\sum_{n=1}^{59}(-1)^n$.

  7. Calculate the total

    $5\sum_{n=1}^{59}n=5\cdot\dfrac{59\cdot60}{2}=8850$, and $\sum_{n=1}^{59}(-1)^n=-1$. Therefore the total is $8850-3=8847$.

Final answer

$(i)$ Proven. $\quad (ii)(a)\ 22.\quad (ii)(b)\ 8847$.

17. WMA12/01 October 2019 · Q7

Medium7 marks · main topic: Laws of Logarithms
Show worked solution
  1. Use the given logarithm

    Since $\log_a b=k$, we can replace every $\log_a b$ by $k$.

  2. Simplify part (i)

    $\log_a\left(\dfrac{\sqrt a}{b}\right)=\log_a(a^{1/2})-\log_a b=\dfrac12-k$.

  3. Simplify the numerator and denominator

    $\log_a(a^2b)=\log_a a^2+\log_a b=2+k$, and $\log_a(b^3)=3\log_a b=3k$.

  4. Write part (ii)

    Therefore $\dfrac{\log_a(a^2b)}{\log_a(b^3)}=\dfrac{k+2}{3k}$.

  5. Simplify the summand

    $\log_a(b^n)=n\log_a b=nk$, so $k+\log_a(b^n)=k+nk=(n+1)k$.

  6. Sum the series

    $\sum_{n=1}^{50}(n+1)k=k\left(\sum_{n=1}^{50}n+50\right)=k(1275+50)=1325k$.

Final answer

$(i)\ \dfrac12-k.\quad (ii)\ \dfrac{k+2}{3k}.\quad (iii)\ 1325k$.

18. WMA12/01 January 2024 · Q5

  1. Identify the geometric series

    $\displaystyle \sum_{r=1}^{\infty}6(0.25)^r$ has first term $6(0.25)=1.5$ and common ratio $0.25$.

  2. Sum to infinity

    $S_\infty=\dfrac{1.5}{1-0.25}=\dfrac{1.5}{0.75}=2$.

  3. Find the first few terms

    $u_1=3$. Then $u_2=\dfrac{3-3}{3-2}=0$.

  4. Continue the recurrence

    $u_3=\dfrac{0-3}{0-2}=\dfrac32$, and $u_4=\dfrac{\frac32-3}{\frac32-2}=3$.

  5. Show periodicity

    Since $u_4=3=u_1$, the terms repeat as $3,0,\dfrac32,3,0,\dfrac32,\ldots$.

  6. State the order

    The repeating cycle has length $3$, so the order is $3$.

  7. Sum one cycle

    One full cycle sums to $3+0+\dfrac32=\dfrac92$.

  8. Use 70 terms

    Since $70=23\cdot3+1$, the first $70$ terms contain $23$ complete cycles and one extra term $u_1=3$.

  9. Find the required sum

    $\displaystyle \sum_{n=1}^{70}u_n=23\left(\dfrac92\right)+3=\dfrac{207}{2}+\dfrac{6}{2}=\dfrac{213}{2}$.

Final answer

$(i)$ $2$. $\quad (ii)(a)$ Periodic. $\quad (ii)(b)$ Order $3$. $\quad (ii)(c)$ $\dfrac{213}{2}$.
