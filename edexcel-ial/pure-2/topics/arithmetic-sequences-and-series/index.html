3. WMA12/01 October 2024 · Q7

Easy6 marks · main topic: Modelling with Sequences & Series
Show worked solution
  1. Identify Jem's sequence

    Jem's payments are arithmetic with first term $20$ and common difference $0.50$.

  2. Show month 100

    The month $100$ payment is $20+99(0.50)=69.50$, so Jem pays £69.50.

  3. Sum Jem's payments

    $S_{300}=\dfrac{300}{2}\{2(20)+299(0.50)\}=150(189.5)=28425$.

  4. Model Kim's payments

    Let the common ratio be $r$. Since the first payment is $20$ and the month $300$ payment is $250$, $20r^{299}=250$.

  5. Find the ratio

    Thus $r^{299}=12.5$ and $r=12.5^{1/299}$.

  6. Sum Kim's payments

    $S_B=20\dfrac{r^{300}-1}{r-1}$ with $r=12.5^{1/299}$, giving $S_B\approx27362.95$.

  7. Find the difference

    The difference is $28425-27362.95\approx1062.05$, which is £1,060 to the nearest £10.

Final answer

$(a)$ Proven. $\quad (b)$ £28,425. $\quad (c)$ £1,060.

4. WMA12/01 October 2021 · Q5

  1. Identify the arithmetic sequence

    The first term is $480$ and the common difference is $465-480=-15$.

  2. Find year fourteen

    $u_{14}=480+13(-15)=285$, so $285$ tonnes were extracted in year $14$.

  3. Set up the total

    The total after $N$ years is $S_N=\dfrac N2\{2(480)+(N-1)(-15)\}$.

  4. Use the total extraction

    $\dfrac N2(975-15N)=7770$.

  5. Show the quadratic

    Multiplying by $2$ and rearranging gives $15N^2-975N+15540=0$, so $N^2-65N+1036=0$.

  6. Solve and choose N

    $N=28$ or $37$. Since extraction amounts would become negative before year $37$, the stopping year is $N=28$.

Final answer

$(a)\ 285$ tonnes. $\quad (b)$ Proven: $N^2-65N+1036=0$. $\quad (c)\ N=28$.

5. WMA12/01 May/June 2024 · Q2

Medium7 marks
Show worked solution
  1. Use the sixth term

    For an arithmetic series, $u_6=a+5d=2$.

  2. Use the sum of ten terms

    $S_{10}=\dfrac{10}{2}(2a+9d)=-80$, so $2a+9d=-16$.

  3. Solve simultaneously

    From $a+5d=2$, $a=2-5d$. Substitute into $2a+9d=-16$.

  4. Find a and d

    $2(2-5d)+9d=-16$, so $4-d=-16$ and $d=20$. Then $a=2-5(20)=-98$.

  5. Write S n

    $S_n=\dfrac n2(2a+(n-1)d)=\dfrac n2(-196+20n-20)=10n^2-108n$.

  6. Set up the inequality

    We need $10n^2-108n>8000$.

  7. Solve the boundary

    $10n^2-108n-8000=0$ gives $5n^2-54n-4000=0$.

  8. Find the positive threshold

    $n=\dfrac{54+\sqrt{82916}}{10}=34.195\ldots$.

  9. Choose the smallest integer

    Therefore the smallest integer value with $S_n>8000$ is $n=35$.

Final answer

$(a)$ First term $=-98$, common difference $=20$. $\quad (b)$ $n=35$.

6. WMA12/01 October 2023 · Q8

Medium7 marks
Show worked solution
  1. Use the arithmetic sum formula

    The first term is $a$ and the common difference is $4$.

  2. Use the first 10 rows

    $S_{10}=\dfrac{10}{2}\left(2a+9\cdot4\right)=360$.

  3. Find a

    $5(2a+36)=360$, so $10a+180=360$ and $a=18$.

  4. Write S n

    $S_n=\dfrac n2\left(2(18)+(n-1)4\right)=\dfrac n2(4n+32)=2n^2+16n$.

  5. Use the total number of seats

    Since the total is $2146$, $2n^2+16n=2146$.

  6. Show the equation

    Dividing by $2$ and rearranging gives $n^2+8n-1073=0$.

  7. Solve for n

    $n=\dfrac{-8\pm\sqrt{8^2+4(1073)}}{2}=\dfrac{-8\pm66}{2}$, so $n=29$ or $n=-37$.

  8. Choose the row count

    The number of rows must be positive, so there are $29$ rows.

  9. Find the maximum row size

    The largest row is the last row: $18+(29-1)4=18+112=130$ seats.

Final answer

$(a)$ $a=18$. $\quad (b)$ Proven. $\quad (c)(i)$ $29$ rows. $\quad (c)(ii)$ $130$ seats.

7. WMA12/01 January 2023 · Q3

Medium7 marks · main topic: Binomial Expansion
Show worked solution
  1. Start the binomial expansion

    $\left(2+\dfrac{kx}{8}\right)^7$ begins with $2^7+7(2^6)\left(\dfrac{kx}{8}\right)+\binom72(2^5)\left(\dfrac{kx}{8}\right)^2+\binom73(2^4)\left(\dfrac{kx}{8}\right)^3$.

  2. Simplify the terms

    This gives $128+56kx+\dfrac{21}{2}k^2x^2+\dfrac{35}{32}k^3x^3$.

  3. Use the arithmetic progression condition

    The coefficients of $x$, $x^2$ and $x^3$ are $56k$, $\dfrac{21}{2}k^2$ and $\dfrac{35}{32}k^3$.

  4. Set middle twice

    For three terms in an arithmetic progression, twice the middle term equals the sum of the outer terms: $21k^2=56k+\dfrac{35}{32}k^3$.

  5. Use k non-zero

    Since $k\ne0$, divide by $k$ and multiply by $32$: $672k=1792+35k^2$.

  6. Solve the quadratic

    So $35k^2-672k+1792=0$. The discriminant is $672^2-4(35)(1792)=200704=448^2$.

  7. Find the possible values

    $k=\dfrac{672\pm448}{70}$, giving $k=16$ or $k=\dfrac{16}{5}$.

Final answer

$(a)$ $128+56kx+\dfrac{21}{2}k^2x^2+\dfrac{35}{32}k^3x^3$. $\quad (b)$ $k=\dfrac{16}{5}$ or $k=16$.

8. WMA12/01 May/June 2021 · Q1

Medium7 marks · main topic: Modelling with Sequences & Series
Show worked solution
  1. Choose the model

    The weekly amounts are $5$, $5.25$, $5.50$, and so on. The increase is a constant $0.25$, so an arithmetic series should be used.

  2. Write the nth amount

    The first amount is $5$ and the common difference is $0.25$, so the amount saved in week $n$ is $5+0.25(n-1)$.

  3. Set up the total

    After $n$ weeks, $S_n=\dfrac n2\{2(5)+(n-1)(0.25)\}$.

  4. Form the inequality

    Adina needs $S_n\geq350$, so $\dfrac n2(9.75+0.25n)\geq350$.

  5. Solve for n

    This is $n^2+39n-2800\geq0$. The positive root is $36.89\ldots$, so the first whole number that works is $n=37$.

  6. Check the week

    After $36$ weeks the total is below $350$, and after $37$ weeks it is $351.50$, so it takes $37$ weeks.

Final answer

$(a)(i)$ Arithmetic series. $\quad (a)(ii)\ 5+0.25(n-1)$. $\quad (b)\ 37$ weeks.

9. WMA12/01 January 2020 · Q8

Medium7 marks · main topic: Sequences & Series
Show worked solution
  1. Write the series forwards

    $S_n=a+(a+d)+(a+2d)+\cdots+(a+(n-1)d)$.

  2. Write the series backwards

    $S_n=(a+(n-1)d)+(a+(n-2)d)+\cdots+a$.

  3. Add the two forms

    Each pair adds to $2a+(n-1)d$, and there are $n$ pairs. Hence $2S_n=n\{2a+(n-1)d\}$.

  4. Complete the proof

    Dividing by $2$ gives $S_n=\dfrac n2\{2a+(n-1)d\}$.

  5. Find u5

    $u_5=5(5)+3(-1)^5=25-3=22$.

  6. Sum the sequence

    $\sum_{n=1}^{59}u_n=5\sum_{n=1}^{59}n+3\sum_{n=1}^{59}(-1)^n$.

  7. Calculate the total

    $5\sum_{n=1}^{59}n=5\cdot\dfrac{59\cdot60}{2}=8850$, and $\sum_{n=1}^{59}(-1)^n=-1$. Therefore the total is $8850-3=8847$.

Final answer

$(i)$ Proven. $\quad (ii)(a)\ 22.\quad (ii)(b)\ 8847$.

10. WMA12/01 May/June 2025 · Q7

Hard9 marks · main topic: Sequences & Series
Show worked solution
  1. Identify the geometric sequence

    The first term is $10$ and the common ratio is $\dfrac{8}{10}=0.8$.

  2. Find the sum to infinity

    $S_\infty=\dfrac{10}{1-0.8}=50$.

  3. Write the kth term

    The $k$th term is $10(0.8)^{k-1}$.

  4. Use the inequality

    $10(0.8)^{k-1}<0.0005$, so $(0.8)^{k-1}<0.00005$.

  5. Solve with logarithms

    Taking logarithms gives $(k-1)\log(0.8)<\log(0.00005)$. Since $\log(0.8)<0$, $k-1>\dfrac{\log(0.00005)}{\log(0.8)}=44.381\ldots$.

  6. Find the smallest integer

    Thus $k>45.381\ldots$, so the smallest possible value is $k=46$.

  7. Write the arithmetic sum

    For $850+843+836+\cdots$, the first term is $850$ and the common difference is $-7$.

  8. Form S n

    $S_n=\dfrac n2\{2(850)+(n-1)(-7)\}=\dfrac n2(1707-7n)$.

  9. Find the best integer n

    This quadratic has its maximum near $n=\dfrac{1707}{14}=121.928\ldots$, so check $n=122$.

  10. Find the greatest sum

    $S_{122}=\dfrac{122}{2}(1707-854)=61(853)=52033$.

Final answer

$(i)(a)$ $50$. $\quad (i)(b)$ $46$. $\quad (ii)$ $52033$.

11. WMA12/01 January 2024 · Q7

Hard9 marks · main topic: Modelling with Sequences & Series
Show worked solution
  1. Model A common difference

    Model A is arithmetic. From year 1 to year 12 there are $11$ equal increases, so $d=\dfrac{4000-300}{11}=\dfrac{3700}{11}$.

  2. Find year 4 in model A

    Year 4 is $300+3d=300+3\left(\dfrac{3700}{11}\right)=1309.09\ldots$, so the amount is $1310$ tonnes to the nearest $10$ tonnes.

  3. Model B common ratio

    Model B is geometric. If the ratio is $r$, then $300r^{11}=4000$.

  4. Find the ratio

    $r=\left(\dfrac{4000}{300}\right)^{1/11}=1.2655\ldots$.

  5. Find year 2 in model B

    Year 2 is $300r=379.65\ldots$, so the amount is $380$ tonnes to the nearest $10$ tonnes.

  6. Total for model A

    $S_A=\dfrac{12}{2}(300+4000)=25800$ tonnes.

  7. Total for model B

    $S_B=300\dfrac{r^{12}-1}{r-1}=17935.20\ldots$ tonnes.

  8. Find the difference

    The difference is $25800-17935.20\ldots=7864.79\ldots$, which is $7860$ tonnes to the nearest $10$ tonnes.

Final answer

$(a)$ $1310$ tonnes. $\quad (b)$ $380$ tonnes. $\quad (c)$ $7860$ tonnes.

12. WMA12/01 January 2022 · Q8

Hard9 marks · main topic: Modelling with Sequences & Series
Show worked solution
  1. Use the arithmetic rule

    For the first $20$ hits, the additional distances form an arithmetic sequence with first term $100$ and common difference $-2$.

  2. Show the twentieth hit

    The twentieth additional distance is $100+19(-2)=62$ mm.

  3. Sum the first twenty hits

    $S_{20}=\dfrac{20}{2}(100+62)=1620$ mm.

  4. Use the geometric information

    After the twentieth hit, the distances follow the same ratio, so the twenty second distance is $62r^2$.

  5. Find r

    $62r^2=60$, hence $r=\sqrt{\dfrac{30}{31}}=0.984$ to 3 decimal places.

  6. Set up the remaining distance

    More than $3$ m means more than $3000$ mm. After $20$ hits, the remaining amount to exceed is $3000-1620=1380$ mm.

  7. Sum the geometric tail

    If there are $m$ further hits, their total is $62r+62r^2+\cdots+62r^m=62r\dfrac{1-r^m}{1-r}$.

  8. Find the first m that works

    Using $r=\sqrt{30/31}$, $62r\dfrac{1-r^{27}}{1-r}$ is not enough, but $62r\dfrac{1-r^{28}}{1-r}$ makes the total exceed $3000$ mm.

  9. State N

    Therefore $m=28$ further hits are needed after the first $20$, so $N=20+28=48$.

Final answer

$(a)$ Proven: $62$ mm. $\quad (b)\ 1620$ mm. $\quad (c)\ r=0.984.\quad (d)\ N=48$.

13. WMA12/01 January 2026 · Q9

Hard10 marks · main topic: Modelling with Sequences & Series
Show worked solution
  1. Model A as an arithmetic sequence

    For Model A, let the common difference be $d$. Since year 15 is the 15th term, $7500=12400+14d$.

  2. Find year 5 for Model A

    $d=\dfrac{7500-12400}{14}=-350$. Year 5 is $12400+4(-350)=11000$ tonnes.

  3. Find the total from year 1 to year 15

    $S_{15}=\dfrac{15}{2}(12400+7500)=149250$ tonnes.

  4. Model B as a geometric sequence

    Let the common ratio be $r$. Then $7500=12400r^{14}$, so $r=\left(\dfrac{7500}{12400}\right)^{1/14}\approx0.964723$.

  5. Find year 10 for Model B

    Year 10 is $12400r^9\approx8975.26$, which is $8980$ tonnes to the nearest 10 tonnes.

  6. Find the limiting total

    Since $0<r<1$, the sum to infinity is $S_\infty=\dfrac{12400}{1-r}\approx351508.1$, so the limit is $351500$ tonnes to the nearest 100 tonnes.

Final answer

$(a)\ 11000$ tonnes. $\quad (b)\ 149250$ tonnes. $\quad (c)\ 8980$ tonnes. $\quad (d)\ 351500$ tonnes.

14. WMA12/01 January 2021 · Q10

Hard11 marks · main topic: Modelling with Sequences & Series
Show worked solution
  1. Find the arithmetic difference

    Plan A has $12$ Sunday runs from $15$ km to $37$ km, so there are $11$ equal increases. The common difference is $\dfrac{37-15}{11}=2$.

  2. Find week five for plan A

    Week $5$ is the fifth term, so the distance is $15+4(2)=23\text{ km}$.

  3. Find the geometric ratio

    For plan B, $15r^{11}=37$, so $r=\left(\dfrac{37}{15}\right)^{1/11}$.

  4. Find week five for plan B

    The fifth Sunday distance is $15r^4=15\left(\dfrac{37}{15}\right)^{4/11}=20.829\ldots$, so it is $20.8\text{ km}$.

  5. Sum the Sunday runs for plan A

    The arithmetic total is $\dfrac{12}{2}(15+37)=312$ km.

  6. Find the Wednesday limit for plan A

    The total distance condition gives $312+12x\leq360$, so $x\leq4$. The maximum integer is $4$.

  7. Sum the Sunday runs for plan B

    The geometric total is $15\dfrac{r^{12}-1}{r-1}=294.185\ldots$ km.

  8. Find the Wednesday limit for plan B

    Now $294.185\ldots+12x\leq360$, so $x\leq5.484\ldots$. The maximum integer is $5$.

Final answer

$(a)\ 23\text{ km}.\quad (b)\ 20.8\text{ km}.\quad (c)(i)\ x=4.\quad (c)(ii)\ x=5$.

15. WMA12/01 October 2019 · Q9

Hard12 marks · main topic: Trigonometric Equations
Show worked solution
  1. Solve the sine equation

    Let $u=2\theta-10^\circ$. Then $\sin u=\dfrac13$.

  2. Find the valid angle values

    Since $0\leq\theta<180^\circ$, $-10^\circ\leq u<350^\circ$. In this interval, $u=19.471\ldots^\circ$ or $u=160.529\ldots^\circ$.

  3. Return to theta

    $\theta=\dfrac{u+10^\circ}{2}$, giving $\theta=14.7^\circ$ and $85.3^\circ$ to one decimal place.

  4. Use the arithmetic sequence condition

    For three consecutive terms of an arithmetic sequence, second minus first equals third minus second. Hence $\dfrac1{\tan\alpha}-\sin\alpha=2\sin\alpha-\dfrac1{\tan\alpha}$.

  5. Prove the required identity

    This gives $\dfrac2{\tan\alpha}=3\sin\alpha$. Since $\dfrac1{\tan\alpha}=\dfrac{\cos\alpha}{\sin\alpha}$, we get $\dfrac{2\cos\alpha}{\sin\alpha}=3\sin\alpha$, so $2\cos\alpha=3\sin^2\alpha$.

  6. Form a quadratic in cos alpha

    Using $\sin^2\alpha=1-\cos^2\alpha$, $2\cos\alpha=3(1-\cos^2\alpha)$, so $3\cos^2\alpha+2\cos\alpha-3=0$.

  7. Solve in the given interval

    $\cos\alpha=\dfrac{-1+\sqrt{10}}{3}$; the other root is less than $-1$. Since $\pi<\alpha<2\pi$ and cosine is positive, $\alpha$ is in the fourth quadrant.

  8. State alpha

    $\alpha=2\pi-\cos^{-1}\left(\dfrac{-1+\sqrt{10}}{3}\right)=5.517$ radians to 3 decimal places.

Final answer

$(i)\ \theta=14.7^\circ,\ 85.3^\circ.\quad (ii)(a)$ Proven. $\quad (ii)(b)\ \alpha=5.517$ radians.

16. WMA12/01 May/June R 2024 · Q8

Hard13 marks
Show worked solution
  1. Write the first and last terms

    The first term is $a$ and the $n$th term is $a+(n-1)d$.

  2. Use the arithmetic sum formula

    $S_n=\dfrac n2(\text{first term}+\text{last term})$.

  3. Show the formula

    Therefore $S_n=\dfrac n2\{a+[a+(n-1)d]\}=\dfrac n2\{2a+(n-1)d\}$.

  4. Identify the arithmetic series

    For $900+892+884+\cdots+500$, the first term is $900$, the common difference is $-8$, and the last term is $500$.

  5. Find the number of terms

    $500=900+(n-1)(-8)$, so $n-1=50$ and $n=51$.

  6. Find the sum

    $S=\dfrac{51}{2}(900+500)=35700$.

  7. Use the geometric condition

    For $k+4$, $k-2$, $11-k$ to be consecutive geometric terms, $(k-2)^2=(k+4)(11-k)$.

  8. Show the quadratic

    $k^2-4k+4=-k^2+7k+44$, so $2k^2-11k-40=0$.

  9. Solve for k

    $2k^2-11k-40=0$ gives $k=8$ or $k=-\dfrac52$.

  10. Use convergence

    If $k=8$, the terms are $12,6,3$ and the common ratio is $\dfrac12$, so the series is convergent. If $k=-\dfrac52$, the common ratio is $-3$, so it is not convergent.

  11. Find S infinity

    Use $k=8$: $S_\infty=\dfrac{12}{1-1/2}=24$.

Final answer

$(i)(a)$ Proven. $\quad (i)(b)$ $35700$. $\quad (ii)(a)$ Proven. $\quad (ii)(b)$ $S_\infty=24$.
