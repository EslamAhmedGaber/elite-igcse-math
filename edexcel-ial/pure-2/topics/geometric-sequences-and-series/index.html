4. WMA12/01 January 2023 · Q7

Medium7 marks

  1. Write the given terms

    For a geometric sequence, the third term is $ar^2=20$ and the fifth term is $ar^4=12.8$.

  2. Divide the equations

    $\dfrac{ar^4}{ar^2}=\dfrac{12.8}{20}$, so $r^2=0.64$.

  3. Use r positive

    Since $r>0$, $r=0.8$.

  4. Find a

    Using $ar^2=20$, $a(0.8)^2=20$, so $a=\dfrac{20}{0.64}=31.25$.

  5. Write the sum formula

    $S_n=\dfrac{a(1-r^n)}{1-r}=\dfrac{31.25(1-0.8^n)}{0.2}=156.25(1-0.8^n)$.

  6. Set up the inequality

    We need $156.25(1-0.8^n)>156$.

  7. Isolate the power

    $1-0.8^n>\dfrac{156}{156.25}=\dfrac{624}{625}$, so $0.8^n<\dfrac{1}{625}$.

  8. Use logarithms

    $n\log(0.8)<\log\left(\dfrac{1}{625}\right)$. Since $\log(0.8)<0$, dividing reverses the inequality: $n>\dfrac{\log(1/625)}{\log(0.8)}=28.85\ldots$.

  9. Choose the smallest integer

    The smallest possible integer value is therefore $n=29$.

Final answer

$(a)$ $r=0.8$. $\quad (b)$ $a=31.25$. $\quad (c)$ $n=29$.

    $S_n=a+ar+ar^2+\cdots+ar^{n-1}$.

  2. Multiply by r

    $rS_n=ar+ar^2+ar^3+\cdots+ar^n$.

  3. Subtract

    $S_n-rS_n=a-ar^n=a(1-r^n)$.

  4. Rearrange

    $(1-r)S_n=a(1-r^n)$, so $S_n=\dfrac{a(1-r^n)}{1-r}$.

  5. Use the yearly multiplier

    An $8\%$ decrease each year means the multiplier is $0.92$.

  6. Show the amount after six years

  7. Set up the forty barrel total

    At the end of $40$ years, the amounts are $150(0.92),150(0.92)^2,\ldots,150(0.92)^{40}$.

  8. Sum the geometric sequence

    The total is $150(0.92)\dfrac{1-0.92^{40}}{1-0.92}=1663.581\ldots$.

  9. Round the total

    To the nearest litre, the total amount is $1664$ litres.

Final answer

8. WMA12/01 January 2024 · Q5

Medium8 marks · main topic: Sequences & Series
Show worked solution
  1. Identify the geometric series

    $\displaystyle \sum_{r=1}^{\infty}6(0.25)^r$ has first term $6(0.25)=1.5$ and common ratio $0.25$.

  2. Sum to infinity

    $S_\infty=\dfrac{1.5}{1-0.25}=\dfrac{1.5}{0.75}=2$.

  3. Find the first few terms

    $u_1=3$. Then $u_2=\dfrac{3-3}{3-2}=0$.

  4. Continue the recurrence

    $u_3=\dfrac{0-3}{0-2}=\dfrac32$, and $u_4=\dfrac{\frac32-3}{\frac32-2}=3$.

  5. Show periodicity

    Since $u_4=3=u_1$, the terms repeat as $3,0,\dfrac32,3,0,\dfrac32,\ldots$.

  6. State the order

    The repeating cycle has length $3$, so the order is $3$.

  7. Sum one cycle

    One full cycle sums to $3+0+\dfrac32=\dfrac92$.

  8. Use 70 terms

    Since $70=23\cdot3+1$, the first $70$ terms contain $23$ complete cycles and one extra term $u_1=3$.

  9. Find the required sum

    $\displaystyle \sum_{n=1}^{70}u_n=23\left(\dfrac92\right)+3=\dfrac{207}{2}+\dfrac{6}{2}=\dfrac{213}{2}$.

Final answer

$(i)$ $2$. $\quad (ii)(a)$ Periodic. $\quad (ii)(b)$ Order $3$. $\quad (ii)(c)$ $\dfrac{213}{2}$.

  1. Use the arithmetic rule

    For the first $20$ hits, the additional distances form an arithmetic sequence with first term $100$ and common difference $-2$.

  2. Show the twentieth hit

    The twentieth additional distance is $100+19(-2)=62$ mm.

  3. Sum the first twenty hits

    $S_{20}=\dfrac{20}{2}(100+62)=1620$ mm.

  4. Use the geometric information

    After the twentieth hit, the distances follow the same ratio, so the twenty second distance is $62r^2$.

  5. Find r

    $62r^2=60$, hence $r=\sqrt{\dfrac{30}{31}}=0.984$ to 3 decimal places.

  6. Set up the remaining distance

    More than $3$ m means more than $3000$ mm. After $20$ hits, the remaining amount to exceed is $3000-1620=1380$ mm.

  7. Sum the geometric tail

    If there are $m$ further hits, their total is $62r+62r^2+\cdots+62r^m=62r\dfrac{1-r^m}{1-r}$.

  8. Find the first m that works

    Using $r=\sqrt{30/31}$, $62r\dfrac{1-r^{27}}{1-r}$ is not enough, but $62r\dfrac{1-r^{28}}{1-r}$ makes the total exceed $3000$ mm.

  9. State N

    Therefore $m=28$ further hits are needed after the first $20$, so $N=20+28=48$.

Final answer

  7. Use the geometric condition

    For $k+4$, $k-2$, $11-k$ to be consecutive geometric terms, $(k-2)^2=(k+4)(11-k)$.

  8. Show the quadratic

    $k^2-4k+4=-k^2+7k+44$, so $2k^2-11k-40=0$.

  9. Solve for k

    $2k^2-11k-40=0$ gives $k=8$ or $k=-\dfrac52$.

  10. Use convergence

    If $k=8$, the terms are $12,6,3$ and the common ratio is $\dfrac12$, so the series is convergent. If $k=-\dfrac52$, the common ratio is $-3$, so it is not convergent.

  11. Find S infinity

    Use $k=8$: $S_\infty=\dfrac{12}{1-1/2}=24$.

Final answer
