  1. Use the factor theorem

    Since $(2x-3)$ is a factor, $x=\dfrac32$ is a root, so $f\left(\dfrac32\right)=0$.

  2. Substitute the root

    $4\left(\dfrac32\right)^3-8\left(\dfrac32\right)^2+5\left(\dfrac32\right)+a=0$.

  3. Find a

    $13.5-18+7.5+a=0$, so $3+a=0$ and $a=-3$.

  4. Write the polynomial

    With $a=-3$, $f(x)=4x^3-8x^2+5x-3$.

  5. Factor using the known factor

    $4x^3-8x^2+5x-3=(2x-3)(2x^2-x+1)$.

  6. Check the quadratic

    The discriminant of $2x^2-x+1$ is $(-1)^2-4(2)(1)=1-8=-7$.

  7. Conclude about real roots

    Since the quadratic has negative discriminant, it has no real roots. Therefore $f(x)=0$ has only the one real root from $2x-3=0$, namely $x=\dfrac32$.

Final answer

$(a)$ $a=-3$. $\quad (b)$ $f(x)=0$ has only one real root, $x=\dfrac32$.

  9. Apply the logarithm domain

Final answer

  1. Write the circle equation

    The circle has centre $(3,5)$ and radius $r$, so $(x-3)^2+(y-5)^2=r^2$.

  2. Substitute the line

    On the line, $y=2x+k$. Substitution gives $(x-3)^2+(2x+k-5)^2=r^2$.

  3. Expand

    $x^2-6x+9+4x^2+4kx-20x+k^2-10k+25-r^2=0$.

  4. Show the intersection equation

    Collecting terms gives $5x^2+(4k-26)x+k^2-10k+34-r^2=0$.

  5. Use tangency

    For a tangent, the quadratic has one repeated root, so its discriminant is zero.

  6. Set the discriminant to zero

    $(4k-26)^2-20(k^2-10k+34-r^2)=0$.

  7. Simplify

    This reduces to $20r^2-4k^2-8k-4=0$, hence $5r^2=(k+1)^2$. Therefore $p=1$.

  8. Find the tangent point x coordinate

    For the repeated root, $x_B=-\dfrac{4k-26}{2\cdot5}=\dfrac{13-2k}{5}$.

  9. Use distance AB

    The point $A$ is $(0,k)$ and $B$ lies on a line of gradient $2$, so $AB=\sqrt{x_B^2+(2x_B)^2}=\sqrt5\,x_B$.

  10. Use the radius relation

    From $5r^2=(k+1)^2$, $r=\dfrac{k+1}{\sqrt5}$ in the shown configuration.

    $\sqrt5\left(\dfrac{13-2k}{5}\right)=2\left(\dfrac{k+1}{\sqrt5}\right)$.

  12. Solve for k

    Multiplying by $\sqrt5$ gives $13-2k=2k+2$, so $k=\dfrac{11}{4}$.
