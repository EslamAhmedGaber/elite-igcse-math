1. WMA12/01 October 2024 · Q6

Easy5 marks
Show worked solution
  1. State the domain

    The logarithms require $12-2x>0$ and $x+1>0$, so $-1<x<6$.

  2. Combine the right hand side

    $2=\log_4(16)$, so $2+2\log_4(x+1)=\log_4\left(16(x+1)^2\right)$.

  3. Equate the arguments

    $\log_4(12-2x)=\log_4\left(16(x+1)^2\right)$ gives $12-2x=16(x+1)^2$.

  4. Form the quadratic

    $12-2x=16x^2+32x+16$, so $8x^2+17x+2=0$.

  5. Factor and solve

    $8x^2+17x+2=(8x+1)(x+2)=0$, so $x=-\dfrac18$ or $x=-2$.

  6. Check the domain

    The value $x=-2$ is outside $-1<x<6$, so the solution is $x=-\dfrac18$.

Final answer

$x=-\dfrac18$.

2. WMA12/01 May/June 2023 · Q5

Easy5 marks
Show worked solution
  1. State the domain

    The logarithms require $16x>0$, $x+1>0$ and $x+6>0$, so $x>0$.

  2. Combine the left side

    $\log_2(16x)+\log_2(x+1)=\log_2(16x(x+1))$.

  3. Rewrite the right side

    $3=\log_2 8$, so $3+\log_2(x+6)=\log_2(8(x+6))$.

  4. Equate the arguments

    Therefore $16x(x+1)=8(x+6)$.

  5. Solve the quadratic

    $16x^2+16x=8x+48$, so $16x^2+8x-48=0$. Dividing by $8$ gives $2x^2+x-6=0$.

  6. Factor and use the domain

    $(2x-3)(x+2)=0$, so $x=\dfrac32$ or $x=-2$. The domain $x>0$ rejects $-2$, leaving $x=\dfrac32$.

Final answer

$x=\dfrac32$.

6. WMA12/01 January 2023 · Q4

Easy6 marks
Show worked solution
  1. Rewrite the constant

    Since $2=\log_3 9$, the equation becomes $\log_3(4x)+\log_3 9=\log_3(5x+7)$.

  2. Combine the logarithms

    $\log_3(4x)+\log_3 9=\log_3(36x)$.

  3. Solve for x

    Therefore $36x=5x+7$, so $31x=7$ and $x=\dfrac{7}{31}$.

  4. Introduce L

    Let $L=\log_a y$. Then $\log_a(y^r)=r\log_a y=rL$.

  5. Evaluate the left sum

    $\displaystyle \sum_{r=1}^{2}\log_a(y^r)=L+2L=3L$.

  6. Evaluate the right sum

    $\displaystyle \sum_{r=1}^{2}(\log_a y)^r=L+L^2$.

  7. Solve for L

    So $3L=L+L^2$, which gives $L^2-2L=0$ and $L(L-2)=0$.

  8. Use the restrictions

    Since $a>1$ and $y>1$, $\log_a y>0$, so $L\ne0$. Hence $L=2$ and $y=a^2$.

Final answer

$(i)$ $x=\dfrac{7}{31}$. $\quad (ii)$ $y=a^2$.

    $\log_2 9=\log_2(3^2)=2\log_2 3=2a$.

12. WMA12/01 October 2019 · Q7

Medium7 marks
Show worked solution
  1. Use the given logarithm

    Since $\log_a b=k$, we can replace every $\log_a b$ by $k$.

  2. Simplify part (i)

    $\log_a\left(\dfrac{\sqrt a}{b}\right)=\log_a(a^{1/2})-\log_a b=\dfrac12-k$.

  3. Simplify the numerator and denominator

    $\log_a(a^2b)=\log_a a^2+\log_a b=2+k$, and $\log_a(b^3)=3\log_a b=3k$.

  4. Write part (ii)

    Therefore $\dfrac{\log_a(a^2b)}{\log_a(b^3)}=\dfrac{k+2}{3k}$.

  5. Simplify the summand

    $\log_a(b^n)=n\log_a b=nk$, so $k+\log_a(b^n)=k+nk=(n+1)k$.

  6. Sum the series

    $\sum_{n=1}^{50}(n+1)k=k\left(\sum_{n=1}^{50}n+50\right)=k(1275+50)=1325k$.

Final answer

$(i)\ \dfrac12-k.\quad (ii)\ \dfrac{k+2}{3k}.\quad (iii)\ 1325k$.
